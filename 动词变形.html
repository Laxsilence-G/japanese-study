一、动词变形基础概念

什么是动词变形？
日语动词会根据不同的意思和语境改变形式，这叫做"动词变形"（活用）。掌握动词变形是日语学习的核心。

1. 动词的三种类型

类型特征例子变形特点
一类动词
（五段动词）		词尾在う段
（うくすつぬむるぐぶ）		書く、飲む、話す
買う、行く、泳ぐ		词尾在あいうえお
五段变化
二类动词
（一段动词）		词尾是る
る前在い段或え段		食べる、見る
起きる、寝る		去掉る
加其他词尾
三类动词
（不规则动词）		只有2个
变形不规则		する（做）
来る（来）		特殊变形
必须记忆
⚠️ 一类动词的例外
走る（はしる）= 跑、帰る（かえる）= 回、入る（はいる）= 进入、知る（しる）= 知道、切る（きる）= 切
这些动词词尾是る，る前在い段，但它们是一类动词！必须单独记忆。

2. 动词判断流程

✅ 判断步骤
  1. 看词尾是不是る？ 不是る → 一类动词；是る → 继续判断
  2. 看る前面的假名在哪个段？ い段或え段 → 可能是二类动词；其他段 → 一类动词
  3. 检查是否是例外？ 走る、帰る、入る、知る等 → 一类动词
  4. 是否是する或来る？ 是 → 三类动词

二、ます形（礼貌体）

ます形是什么？表示礼貌的动词形式，用于对长辈、上司、陌生人说话。

1. 一类动词 → ます形

变形规则：词尾う段 → い段 + ます
原形词尾变化ます形意思
書く（かく）く → き書きます写
飲む（のむ）む → み飲みます喝
話す（はなす）す → し話します说
買う（かう）う → い買います买
行く（いく）く → き行きます去
💡 记忆口诀
う段 → い段 + ます（く→き、む→み、す→し、つ→ち、ぬ→に、る→り、ぐ→ぎ、ぶ→び、う→い）

2. 二类动词 → ます形

变形规则：去掉る + ます
原形变化ます形意思
食べる去掉る食べます吃
見る去掉る見ます看
起きる去掉る起きます起床

3. 三类动词 → ます形

变形规则：特殊变形，必须记忆！
原形ます形意思注意
するします做する → します
来る（くる）来ます（きます）来汉字"来"读音变化：く → き

三、ます形的四种变化

ます形有四种基本变化：肯定、否定、过去、过去否定。适用于所有动词，规则统一！
形式变化规则意思例句
肯定〜ます做...書きます（写）
否定〜ません不做...書きません（不写）
过去〜ました做了...書きました（写了）
过去否定〜ませんでした没做...書きませんでした（没写）
💡 记忆口诀
ます变ません（否定）、ます变ました（过去）、ません + でした（过去否定）

四、て形（连接形式）

て形是什么？用于连接句子、表示动作顺序、请求等。是日语中最重要的变形之一。

1. 一类动词 → て形

⚠️ 一类动词て形变化规则
词尾变化例子记忆口诀
くく → いて書く → 書いてい音变
ぐぐ → いで泳ぐ → 泳いで
すす → して話す → 話してす→して
ぬ、ぶ、むぬ/ぶ/む → んで死ぬ→死んで、遊ぶ→遊んで、飲む→飲んで拨音变
つ、る、うつ/る/う → って立つ→立って、走る→走って、買う→買って促音变
⚠️ 特殊例外：行く
行く → 行って（不是"行いて"）这是唯一一个く结尾但不变成いて的动词！

2. 二类动词 → て形

变形规则：去掉る + て
原形变化て形意思
食べる去掉る + て食べて吃
見る去掉る + て見て看

3. 三类动词 → て形

原形て形意思
するして做
来る（くる）来て（きて）来

4. て形的用法

朝起きて、顔を洗って、朝ご飯を食べます。
早上起床、洗脸、吃早饭。（动作顺序）
ここに名前を書いてください。
请在这里写名字。（请求）
今、日本語を勉強しています。
现在正在学习日语。（正在进行）

五、ない形（否定形式）

ない形是什么？表示"不做..."的简体形式。

1. 一类动词 → ない形

变形规则：词尾う段 → あ段 + ない
原形词尾变化ない形意思
書くく → か書かない不写
飲むむ → ま飲まない不喝
買うう → わ買わない不买
⚠️ 注意：う → わ
词尾是"う"的动词，变成ない形时是"わ"，不是"あ"！買う → 買わない（正确）

2. 二类动词 → ない形

变形规则：去掉る + ない
原形变化ない形意思
食べる去掉る + ない食べない不吃
見る去掉る + ない見ない不看

3. 三类动词 → ない形

原形ない形意思
するしない不做
来る（くる）来ない（こない）不来
⚠️ 来る的特殊变化
来る → 来ない（こない）汉字"来"读音变化：く → こ

六、た形（过去形式）

た形是什么？表示"做了..."的简体形式。变形规则与て形完全相同，只是把て换成た、で换成だ。
💡 记忆技巧
て形的て → た、て形的で → だ，只需要把最后一个假名改一下！

六-1、たい形（想要做……）

たい形是什么？「たい形」用来表示“想做某事”。例如：行きたい = 想去、食べたい = 想吃、勉強したい = 想学习。
💡 最重要的核心
不管是一类、二类还是三类动词，たい形都先看ます形。也就是说：先变成ます形，再去掉ます，加たい。

1. たい形的基本变法

总规则：动词ます形去ます + たい
动词类型原形先变ます形たい形意思
一类書く書きます書きたい想写
一类飲む飲みます飲みたい想喝
一类行く行きます行きたい想去
二类食べる食べます食べたい想吃
二类見る見ます見たい想看
三类するしますしたい想做
三类来る（くる）来ます（きます）来たい（きたい）想来
⚠️ 易错点
不是「行く → 行くたい」✗，也不是「食べる → 食べるたい」✗。必须先经过ます形：行きます → 行きたい、食べます → 食べたい。

2. 三类动词分别怎么变

一类动词：書く → 書きます → 書きたい
先把词尾从う段变到い段，再加ます；最后去掉ます，加たい。
二类动词：食べる → 食べます → 食べたい
二类动词本来就容易变ます形，所以たい形也很好变。
三类动词：する → します → したい ／ 来る → 来ます → 来たい
三类动词先记住它们的ます形，然后再加たい。

3. たい形后面还可以继续变形

为什么可以继续变？
因为「たい」在语法性质上接近い形容词。所以它后面的变化，很多地方像い形容词。
形式例子（行く）意思
肯定行きたい想去
礼貌形行きたいです想去（礼貌）
否定行きたくない不想去
过去行きたかった之前想去
过去否定行きたくなかった之前不想去
💡 一眼记忆
たい → たくない → たかった → たくなかった，这套变化和い形容词很像：高い → 高くない → 高かった → 高くなかった。

4. たい形的用法与注意点

私は日本へ行きたいです。
我想去日本。
今日は何を食べたいですか。
今天你想吃什么？
この町で子どもを育てたいと思っています。
我正打算在这个城镇养育孩子。
⚠️ 注意1：主要表示说话人的愿望
最基础的用法是说“我想……”。问对方时也很常见：何を飲みたいですか。
如果说第三人称“他想……”，更自然的进阶说法常是「〜たがる」，这是后面会学到的内容。
⚠️ 注意2：助词先记基础用法
初学阶段先牢牢记住：名词 + を + 动词たい。例如：寿司を食べたい、日本語を勉強したい。以后你会看到有些句子也用「が」，但现阶段先把「を」用稳最重要。

買う買います買って買わない買った買いたい

二类动词变形总表

原形ます形て形ない形た形たい形
食べる食べます食べて食べない食べた食べたい
見る見ます見て見ない見た見たい
起きる起きます起きて起きない起きた起きたい

三类动词变形总表

原形ます形て形ない形た形たい形
するしますしてしないしたしたい
来る（くる）来ます（きます）来て（きて）来ない（こない）来た（きた）来たい（きたい）

八、学习建议

📚 学习顺序建议
  1. 第一阶段：掌握动词分类（一类、二类、三类）
  2. 第二阶段：熟练ます形及其四种变化
  3. 第三阶段：掌握て形（最重要！）
  4. 第四阶段：学习ない形和た形
  5. 第五阶段：综合练习，在实际句子中运用

加油！动词变形是日语学习的核心，掌握了它，你就掌握了日语的"钥匙"！🔑
