日语动词变形手册

JLPT N3备考 | 开始日期：2026年3月17日

一、动词变形基础概念

什么是动词变形？
日语动词会根据不同的意思和语境改变形式，这叫做"动词变形"（活用）。掌握动词变形是日语学习的核心。

1. 动词的三种类型

类型特征例子变形特点
一类动词
（五段动词）		词尾在う段
（うくすつぬむるぐぶ）		書く、飲む、話す
買う、行く、泳ぐ		词尾在あいうえお
五段变化
二类动词
（一段动词）		词尾是る
る前在い段或え段		食べる、見る
起きる、寝る		去掉る
加其他词尾
三类动词
（不规则动词）		只有2个
变形不规则		する（做）
来る（来）		特殊变形
必须记忆
⚠️ 一类动词的例外
走る（はしる）= 跑、帰る（かえる）= 回、入る（はいる）= 进入、知る（しる）= 知道、切る（きる）= 切
这些动词词尾是る，る前在い段，但它们是一类动词！必须单独记忆。

2. 动词判断流程

✅ 判断步骤
  1. 看词尾是不是る？ 不是る → 一类动词；是る → 继续判断
  2. 看る前面的假名在哪个段？ い段或え段 → 可能是二类动词；其他段 → 一类动词
  3. 检查是否是例外？ 走る、帰る、入る、知る等 → 一类动词
  4. 是否是する或来る？ 是 → 三类动词

3. 拿到一个词，先判断它是不是动词

先记住总原则：不是所有词都会像动词那样变形。先判断词性，再谈变形。
词类最常见外形后面常接什么例子
动词常以う段假名结尾，或「〜る」「する」「来る」ます、ない、て、た、たい書く、食べる、する
い形容词词尾常是「い」くない、かった、くて、く高い、忙しい
な形容词词典里常不带「な」单独出现だ、です、な、に、で静か、元気
名词表示人、事、物、地点、概念だ、です、の、に、になる学生、日本、本
实战判断口诀
① 能不能说「〜ます」？如果原本就是动作，多半是动词。
② 能不能说「〜くない」？如果可以，多半是い形容词。
③ 修饰名词时要不要加「な」？要加的话，多半是な形容词。
④ 能不能说「〜の本」「〜になる」？如果更像事物名称，多半是名词。
⚠️ 重要提醒
词尾只是线索，不是百分之百答案。比如「きれい」虽然以「い」结尾，却是な形容词；「切る（きる）」虽然长得像二类动词，却是一类动词。

4. 为什么看起来很多词后面加ます就成了动词？

这里最容易误会。不是「ます」把词变成了动词，而是：
动词本来就是动词，只是换成了礼貌说法。
书く → 書きます、食べる → 食べます，这两个词在加ます之前就已经是动词了。
原来的词真实情况正确形式错误理解
書く本来就是动词書きます不是「書く + ます」随便拼接
食べる本来就是动词食べます不是名词变动词
勉強本身常先当名词勉強する → 勉強します不能说「勉強ます」
学生名词学生です不能说「学生ます」
きれいな形容词きれいです不能说「きれいます」
你现在要这样理解：
「ます」只接在动词的ます形词干后面。
而像「勉強」这种词之所以能变成动作，是因为它先和する结合，变成「勉強する」这个三类动词，然后才继续变成「勉強します」。

二、ます形（礼貌体）

ます形是什么？表示礼貌的动词形式，用于对长辈、上司、陌生人说话。

1. 一类动词 → ます形

变形规则：词尾う段 → い段 + ます
原形词尾变化ます形意思
書く（かく）く → き書きます写
飲む（のむ）む → み飲みます喝
話す（はなす）す → し話します说
買う（かう）う → い買います买
行く（いく）く → き行きます去
💡 记忆口诀
う段 → い段 + ます（く→き、む→み、す→し、つ→ち、ぬ→に、る→り、ぐ→ぎ、ぶ→び、う→い）

2. 二类动词 → ます形

变形规则：去掉る + ます
原形变化ます形意思
食べる去掉る食べます吃
見る去掉る見ます看
起きる去掉る起きます起床

3. 三类动词 → ます形

变形规则：特殊变形，必须记忆！
原形ます形意思注意
するします做する → します
来る（くる）来ます（きます）来汉字"来"读音变化：く → き

三、ます形的四种变化

ます形有四种基本变化：肯定、否定、过去、过去否定。适用于所有动词，规则统一！
形式变化规则意思例句
肯定〜ます做...書きます（写）
否定〜ません不做...書きません（不写）
过去〜ました做了...書きました（写了）
过去否定〜ませんでした没做...書きませんでした（没写）
💡 记忆口诀
ます变ません（否定）、ます变ました（过去）、ません + でした（过去否定）

四、て形（连接形式）

て形是什么？用于连接句子、表示动作顺序、请求等。是日语中最重要的变形之一。

1. 一类动词 → て形

⚠️ 一类动词て形变化规则
词尾变化例子记忆口诀
くく → いて書く → 書いてい音变
ぐぐ → いで泳ぐ → 泳いで
すす → して話す → 話してす→して
ぬ、ぶ、むぬ/ぶ/む → んで死ぬ→死んで、遊ぶ→遊んで、飲む→飲んで拨音变
つ、る、うつ/る/う → って立つ→立って、走る→走って、買う→買って促音变
⚠️ 特殊例外：行く
行く → 行って（不是"行いて"）这是唯一一个く结尾但不变成いて的动词！

2. 二类动词 → て形

变形规则：去掉る + て
原形变化て形意思
食べる去掉る + て食べて吃
見る去掉る + て見て看

3. 三类动词 → て形

原形て形意思
するして做
来る（くる）来て（きて）来

4. て形的用法

朝起きて、顔を洗って、朝ご飯を食べます。
早上起床、洗脸、吃早饭。（动作顺序）
ここに名前を書いてください。
请在这里写名字。（请求）
今、日本語を勉強しています。
现在正在学习日语。（正在进行）

五、ない形（否定形式）

ない形是什么？表示"不做..."的简体形式。

1. 一类动词 → ない形

变形规则：词尾う段 → あ段 + ない
原形词尾变化ない形意思
書くく → か書かない不写
飲むむ → ま飲まない不喝
買うう → わ買わない不买
⚠️ 注意：う → わ
词尾是"う"的动词，变成ない形时是"わ"，不是"あ"！買う → 買わない（正确）

2. 二类动词 → ない形

变形规则：去掉る + ない
原形变化ない形意思
食べる去掉る + ない食べない不吃
見る去掉る + ない見ない不看

3. 三类动词 → ない形

原形ない形意思
するしない不做
来る（くる）来ない（こない）不来
⚠️ 来る的特殊变化
来る → 来ない（こない）汉字"来"读音变化：く → こ

六、た形（过去形式）

た形是什么？表示"做了..."的简体形式。变形规则与て形完全相同，只是把て换成た、で换成だ。
💡 记忆技巧
て形的て → た、て形的で → だ，只需要把最后一个假名改一下！

六-1、たい形（想要做……）

たい形是什么？「たい形」用来表示“想做某事”。例如：行きたい = 想去、食べたい = 想吃、勉強したい = 想学习。
💡 最重要的核心
不管是一类、二类还是三类动词，たい形都先看ます形。也就是说：先变成ます形，再去掉ます，加たい。

1. たい形的基本变法

总规则：动词ます形去ます + たい
动词类型原形先变ます形たい形意思
一类書く書きます書きたい想写
一类飲む飲みます飲みたい想喝
一类行く行きます行きたい想去
二类食べる食べます食べたい想吃
二类見る見ます見たい想看
三类するしますしたい想做
三类来る（くる）来ます（きます）来たい（きたい）想来
⚠️ 易错点
不是「行く → 行くたい」✗，也不是「食べる → 食べるたい」✗。必须先经过ます形：行きます → 行きたい、食べます → 食べたい。

2. 三类动词分别怎么变

一类动词：書く → 書きます → 書きたい
先把词尾从う段变到い段，再加ます；最后去掉ます，加たい。
二类动词：食べる → 食べます → 食べたい
二类动词本来就容易变ます形，所以たい形也很好变。
三类动词：する → します → したい ／ 来る → 来ます → 来たい
三类动词先记住它们的ます形，然后再加たい。

3. たい形后面还可以继续变形

为什么可以继续变？
因为「たい」在语法性质上接近い形容词。所以它后面的变化，很多地方像い形容词。
形式例子（行く）意思
肯定行きたい想去
礼貌形行きたいです想去（礼貌）
否定行きたくない不想去
过去行きたかった之前想去
过去否定行きたくなかった之前不想去
💡 一眼记忆
たい → たくない → たかった → たくなかった，这套变化和い形容词很像：高い → 高くない → 高かった → 高くなかった。

4. たい形的用法与注意点

私は日本へ行きたいです。
我想去日本。
今日は何を食べたいですか。
今天你想吃什么？
この町で子どもを育てたいと思っています。
我正打算在这个城镇养育孩子。
⚠️ 注意1：主要表示说话人的愿望
最基础的用法是说“我想……”。问对方时也很常见：何を飲みたいですか。
如果说第三人称“他想……”，更自然的进阶说法常是「〜たがる」，这是后面会学到的内容。
⚠️ 注意2：助词先记基础用法
初学阶段先牢牢记住：名词 + を + 动词たい。例如：寿司を食べたい、日本語を勉強したい。以后你会看到有些句子也用「が」，但现阶段先把「を」用稳最重要。

六-2、各个形态和词性之间的关系

1. 动词 → ます形 → たい形 的关系图

辞書形（原形） 書く ↓ 先按动词规则变形 ます形 書きます ↓ 去掉「ます」 たい形 書きたい ↓ 因为「たい」语法上像 い形容词 继续变化 書きたくない / 書きたかった / 書きたくなかった
关键点只抓一句：
前半段决定“这是哪个动词”，后半段决定“句尾怎么变”。
所以「書きたい」里面，前面的「書き」来自动词「書く」，后面的「たい」让整个句尾表现得像い形容词。

2. サ变名词为什么会像三类动词？

勉強（名词） ↓ 和 する 结合 勉強する（动词，三类） ↓ 礼貌体 勉強します ↓ 愿望 勉強したい
所以你看到很多汉字词好像“突然会动词变形”，本质上是它们走了这条路：
名词 → 名词 + する → 三类动词 → 继续按动词变形
⚠️ 一定不要跳步
不是「勉強 → 勉強たい」✗，而是「勉強する → 勉強したい」✓。
不是「電話 → 電話ました」✗，而是「電話する → 電話しました」✓。

3. 为什么「たい」很像い形容词？

项目い形容词たい形你要记住的结论
否定高い → 高くない行きたい → 行きたくない都用「くない」
过去高い → 高かった行きたい → 行きたかった都用「かった」
过去否定高い → 高くなかった行きたい → 行きたくなかった都用「くなかった」
礼貌高いです行きたいです都能接「です」
最简单理解法
「たい」本身不是普通动词词尾，它更像是贴在动词后面的“想〜”形容词部件。
所以：动词负责动作意义，たい负责“想要”的语法外壳。

六-3、可能形（能够…… / 可以……）

可能形是什么？表示“能做……”“会做……”“在某种条件下可以做……”。这是你做题时非常常遇到、而且从N4到N3都很重要的形态。
你先抓核心意思
食べる = 吃；食べられる = 能吃 / 可以吃
話す = 说；話せる = 会说 / 能说

1. 可能形的基本变法

动词类型原形规则可能形意思
一类書く词尾う段 → え段 + る書ける能写
一类話すす → せる話せる会说
一类読むむ → める読める能读
二类食べる去掉る + られる食べられる能吃
二类見る去掉る + られる見られる能看见 / 能看
三类する特殊变化できる会做 / 能做
三类来る（くる）特殊变化来られる（こられる）能来
💡 一类动词一眼记法
一类动词的可能形，就是う段变え段，再加る：
く→ける、す→せる、む→める、ぶ→べる、ぬ→ねる、う→える、つ→てる、る→れる、ぐ→げる

2. 可能形里助词为什么常从「を」变「が」？

这是做题时最容易卡住的地方。可能句里，原来动作的对象常常从「を」变成「が」。
普通句可能句意思
日本語を話す日本語が話せる会说日语
漢字を読む漢字が読める能读汉字
寿司を食べる寿司が食べられる能吃寿司
⚠️ 先这样记最稳
初学阶段做题时，你先优先记：名词 + が + 可能形。
以后你会看到有些句子也保留「を」，但考试基础题里最常见、最稳妥的是「が」。

3. 可能形的常见陷阱

⚠️ 易错点1：一类动词不要乱套二类规则
書く → 書ける ✓
✗ 書きられる
⚠️ 易错点2：二类动词的可能形不是ます形后面加る
食べる → 食べられる ✓
✗ 食べれる（口语里有人说，但考试标准形先记食べられる）
⚠️ 易错点3：する的可能形不是「しられる」
する → できる，这是必须单独记住的特殊形。
私は日本語が話せます。
我会说日语。
この店では魚が食べられます。
在这家店可以吃鱼。
明日は来られません。
明天不能来。

六-4、除了这些，还有哪些常考形态？

1. 从N5到N3最值得优先掌握的动词形态

优先级形态作用你现在的建议
最高辞書形 / 普通形接各种语法、做从句、做普通表达必须认识并熟悉
最高ている正在…… / 保持某状态一定要补强
最高可能形能…… / 会……现在就该学
高条件形（たら / ば）如果……的话N4-N3非常常见
高意向形要不要…… / 我们来……吧 / 打算……常见且实用
中命令形 / 禁止形命令、禁止先会识别，再慢慢掌握
中受身形被……N3经常会看到
中使役形让……做……N3会出现，先知道概念
结论
就你现在的阶段来说，最该立刻补的就是：可能形、ている、条件形、意向形。
受身形、使役形、命令形、禁止形先做到“见过、能认”，后面再系统学会更合适。

2. 这些常考形态分别是干什么的？

形态例子意思
辞書形書く原形，很多语法都接它
ている書いている正在写 / 一直是写着的状态
可能形書ける能写
たら条件書いたら如果写了 / 要是写的话
ば条件書けば如果写的话
意向形書こう来写吧 / 打算写
命令形書け写！
禁止形書くな别写！
受身形書かれる被写
使役形書かせる让……写

3. 你现在最合理的学习顺序

  1. 先巩固你已经会的：ます形、ます四变、て形、ない形、た形、たい形
  2. 立刻补上：可能形
  3. 接着补：ている、条件形（たら / ば）、意向形
  4. 再进入识别层面：受身形、使役形、命令形、禁止形
⚠️ 很重要
不是说后面的形态不考，而是对你现在来说，如果一下子全背，会很乱。先把高频、好用、立刻能做题的形态学稳，效率最高。

六-5、ている（正在…… / ……着 / 保持某状态）

ている是什么？这是日语里非常高频的形式。它最常见有两种意思：
① 正在进行：今ご飯を食べている（正在吃饭）
② 状态持续：窓が開いている（窗户开着）

1. 一类动词 → ている

规则：先变成て形，再加いる
原形先变て形ている形意思
書く書いて書いている正在写
飲む飲んで飲んでいる正在喝
話す話して話している正在说

2. 二类动词 → ている

规则：先变成て形，再加いる
原形て形ている形意思
食べる食べて食べている正在吃
見る見て見ている正在看
起きる起きて起きている醒着 / 起着

3. 三类动词 → ている

原形て形ている形意思
するしてしている正在做
来る（くる）来て（きて）来ている（きている）来了 / 正在来

4. ている的常见陷阱

⚠️ 陷阱1：不是所有ている都翻成“正在”
住んでいる = 住着 / 住在，不一定翻成“正在住”
結婚している = 已婚 / 结着婚，不是“正在结婚”
⚠️ 陷阱2：自动词常表示结果状态
窓が開いている = 窗户开着
地面がぬれている = 地面湿着 / 地面是湿的
今、日本語を勉強している。
现在正在学习日语。
雨で地面がぬれている。
因为下雨，地面是湿的。

六-6、条件形（たら / ば）

1. たら条件：如果……的话

最简单理解：先变成た形，再加ら。
动词类型原形先变た形たら形
一类書く書いた書いたら
一类飲む飲んだ飲んだら
二类食べる食べた食べたら
二类見る見た見たら
三类するしたしたら
三类来る来た来たら

2. ば条件：如果……的话

动词类型原形规则ば形意思
一类書く词尾う段 → え段 + ば書けば如果写
一类読むむ → めば読めば如果读
二类食べる去掉る + れば食べれば如果吃
二类見る去掉る + れば見れば如果看
三类する特殊变化すれば如果做
三类来る（くる）特殊变化来れば（くれば）如果来
💡 一类动词记忆法
一类动词的ば形和可能形很像：
書く → 書ける（能写） / 書けば（如果写）
読む → 読める（能读） / 読めば（如果读）

3. たら 和 ば 怎么区分？

初学阶段你可以先这样理解：
たら更口语、更宽；ば更像规则、条件判断。
時間があったら、映画を見ます。
如果有时间，就看电影。
安ければ、買います。
如果便宜，就买。
⚠️ 初学建议
做题时先记：たら = た形 + ら；ば = 一类变え段+ば / 二类去る+れば / する→すれば / 来る→くれば。

六-7、意向形（要……吧 / 打算……）

1. 一类动词 → 意向形

规则：词尾う段 → お段 + う
原形变化意向形意思
書くく → こ + う書こう来写吧 / 打算写
話すす → そ + う話そう来说吧
読むむ → も + う読もう来读吧

2. 二类动词 → 意向形

规则：去掉る + よう
原形意向形意思
食べる食べよう来吃吧 / 打算吃
見る見よう来看看吧
起きる起きよう起来吧 / 打算起床

3. 三类动词 → 意向形

原形意向形意思
するしよう来做吧
来る（くる）来よう（こよう）来吧 / 打算来
一緒に勉強しよう。
我们一起学习吧。

4. 意向形的常见陷阱

⚠️ 易错点1
一类动词不是去掉词尾乱加よう。
書く → 書こう ✓ / ✗ 書きよう
⚠️ 易错点2
二类动词才是去掉る + よう。
食べる → 食べよう ✓
常见用法
① 邀请：一緒に行こう。
② 自己的打算：明日から頑張ろうと思う。

六-8、命令形与禁止形

1. 命令形

动词类型规则例子
一类词尾う段 → え段書く → 書け、話す → 話せ、行く → 行け
二类去掉る + ろ / よ食べる → 食べろ、見る → 見ろ
三类特殊变化する → しろ / せよ、来る → 来い（こい）
⚠️ 注意
命令形语气很强，日常对别人直接说会显得凶。考试里常考的是识别，不是让你乱用。

2. 禁止形

规则：辞書形 + な
原形禁止形意思
書く書くな别写
食べる食べるな别吃
するするな别做
来る来るな别来
对比
命令形是“去做！”；禁止形是“别做！”。
这两种都比「〜てください」「〜ないでください」强硬得多。

六-9、受身形（被……）

1. 受身形的基本规则

动词类型规则例子意思
一类词尾う段 → あ段 + れる書く → 書かれる被写
一类す → される話す → 話される被说
二类去掉る + られる食べる → 食べられる被吃
二类去掉る + られる見る → 見られる被看
三类特殊变化する → される、来る → 来られる被做 / 被来

2. 为什么二类动词的受身形和可能形长得像？

这是超级重要的混淆点。二类动词里：
食べる → 食べられる
这个形式既可能是可能形（能吃），也可能是受身形（被吃）。
到底是哪一个，要看句子的意思和助词。
私は魚が食べられる。
我能吃鱼。（可能）
魚は猫に食べられた。
鱼被猫吃了。（受身）

3. 受身句怎么认？

常见标志
① 有“被……”的意思
② 常出现动作发出者：に / によって
③ 句子重点落在“承受动作的一方”
私は先生にほめられた。
我被老师表扬了。
古い方法は新技術によって変えられる。
旧方法会被新技术改变。

六-10、使役形（让……做…… / 使……）

1. 使役形的基本规则

动词类型规则例子意思
一类词尾う段 → あ段 + せる書く → 書かせる让写
一类す → させる話す → 話させる让说
二类去掉る + させる食べる → 食べさせる让吃
二类去掉る + させる見る → 見させる让看
三类特殊变化する → させる、来る → 来させる（こさせる）让做 / 让来

2. 使役形最常见的用法

先生は学生に本を読ませる。
老师让学生读书。
母は子どもに野菜を食べさせる。
妈妈让孩子吃蔬菜。
句型观察
A は B に C を V-させる
＝ A 让 B 做 C 这件事

3. 使役形的常见陷阱

⚠️ 易错点1
一类动词是あ段 + せる，不是去掉词尾直接加させる。
書く → 書かせる ✓ / ✗ 書きさせる
⚠️ 易错点2
二类动词才是去掉る + させる。
食べる → 食べさせる ✓
⚠️ 易错点3
する → させる，来る → 来させる（こさせる），都要单独记。

八、学习建议

📚 学习顺序建议
  1. 第一阶段：掌握动词分类（一类、二类、三类）
  2. 第二阶段：熟练ます形及其四种变化
  3. 第三阶段：掌握て形（最重要！）
  4. 第四阶段：学习ない形和た形
  5. 第五阶段：补上たい形和可能形
  6. 第六阶段：继续进入ている、条件形、意向形
  7. 第七阶段：再系统学习受身形、使役形、命令形、禁止形

加油！动词变形是日语学习的核心，掌握了它，你就掌握了日语的"钥匙"！🔑
