日语语法笔记 - JLPT N3备考

开始日期：2026年3月17日 | 目标考试：2026年7月JLPT N3

N5 语法 LEVEL N5

问候语的时间区分
意思：根据时间段使用不同的问候语
接续：独立使用，无需接续
おはようございます（早晨）→ こんにちは（白天）→ こんばんは（晚上）
早上好 → 你好 → 晚上好
重要：日语问候语严格区分时间段，用错会显得很奇怪。
礼貌体与简体
意思：根据对象选择礼貌程度
接续：独立使用
おはようございます（礼貌）←→ おはよう（随意）
早上好（礼貌）←→ 早（随意）
规则：对长辈、上司、陌生人使用礼貌体；对朋友、家人、晚辈可以使用简体。
动词分类（三类）
意思：日语动词分为三类，变形规则不同
接续：动词原形
一类动词（五段动词）：書く、飲む、話す、買う
二类动词（一段动词）：食べる、見る、起きる、寝る
三类动词（不规则动词）：する、来る
一类：词尾在う段，变形时词尾在五段变化
二类：词尾是る，る前在い/え段
三类：只有两个，变形不规则
判断方法：
1. 词尾不是る → 一类动词
2. 词尾是る，る前在い/え段 → 二类动词
3. する、来る → 三类动词
注意：走る、帰る、入る、知る、蹴る等是一类动词的例外！
动词ます形（礼貌体）
意思：表示礼貌的动词形式
接续：动词原形 → ます形
一类动词：う段 → い段 + ます
書く → 書きます、飲む → 飲みます、話す → 話します

二类动词：去掉る + ます
食べる → 食べます、見る → 見ます、起きる → 起きます

三类动词：特殊变形
する → します、来る → 来ます（きます）
一类：词尾う段变い段
二类：去掉る
三类：特殊记忆
记忆口诀：
一类：う段 → い段 + ます（く→き、む→み、す→し...）
二类：去掉る，加上ます
三类：する→します、来る→来ます（きます）
ます形の四种变化
意思：ます形的肯定、否定、过去、过去否定
接续：ます形基础
形式 变化 意思 例子
肯定 〜ます 做... 書きます（写）
否定 〜ません 不做... 書きません（不写）
过去 〜ました 做了... 書きました（写了）
过去否定 〜ませんでした 没做... 書きませんでした（没写）
记忆口诀：
ます变ません（否定）
ます变ました（过去）
ません + でした（过去否定）
终助词「ね」（寻求共鸣、确认）
意思：表示确认、征求同意、感叹
接续：句子 + ね
すごいね（好厉害啊）
いい天気ですね（好天气啊）
分かるね？（懂了吧？）
そうですね（是啊）
表示感叹
表示感叹
表示确认
表示同意
「ね」的三大作用：
1. 确认：分かるね？（懂了吧？）- 确认对方是否理解
2. 感叹：いい天気ですね（好天气啊）- 表达情感
3. 征求同意：そうですね（是啊）- 寻求共鸣

用法：
• い形容词：直接加ね → すごいね
• な形容词/名词：加だね → 静かだね、学生だね
• 动词：简体加ね → 分かるね、行くね
• 礼貌体：加ですね → すごいですね、分かりますね
い形容词的用法
意思：以"い"结尾的形容词，可直接修饰名词或作谓语
接续：い形容词 + 名词 / 句尾
修饰名词：
すごい人（厉害的人）
おいしい料理（好吃的菜）

作谓语：
この映画はすごい（这部电影很厉害）
すごいね（好厉害啊）
すごいですね（真厉害啊 - 礼貌）
すごい修饰人
おいしい修饰料理

すごい作谓语（简体）
加终助词ね
加です表示礼貌
重要：い形容词作谓语时不需要加"だ"！
✓ すごい（正确）
✗ すごいだ（错误）

礼貌形：い形容词 + です
✓ すごいです（正确）
✓ おいしいです（正确）
助词「が」（主语标记）
意思：提示动作、状态的主体；回答“谁/什么”时常用
接续：名词 + が + 动词/形容词
弟がこれを割ってしまいました。
猫がいます。
何が好きですか。
弟弟把这个弄碎了。
有猫。
你喜欢什么？
重点：
• 「が」前面的词，往往是动作的执行者或状态的主体
• 在本句里，弟が = “弟弟”是“打碎”这个动作的执行者
• 不要和提示主题的「は」混淆：
弟は学生です（说到弟弟，他是学生）
弟が割りました（是弟弟打碎的）
助词「を」（宾语标记）
意思：表示动作直接作用的对象
接续：名词 + を + 他动词
弟がこれを割ってしまいました。
本を読む。
水を飲みます。
弟弟把这个弄碎了。
读书。
喝水。
重点：
• 「を」前面的词，是动作直接影响到的对象
• 本句中 これを = “这个”就是被打碎的东西
• 发音常接近“o”，但写作固定是「を」
助词「に」（目标点 / 着落点）
意思：表示动作到达的位置、附着点、写入的位置
接续：名词（地点） + に
ここに名前を書いてください。
紙に字を書きます。
请在这里写名字。
在纸上写字。
重点：
• 这里的「に」表示写到哪里
• 「ここに身長を書いてください」里，「ここに」就是“在这里 / 写在这里”
• 可以把它理解成动作落下去的地方、填写的位置
• 不要和「で」混淆：に偏向目标点，で偏向动作发生的场所
动词て形（て-form）
意思：连接后续语法，如〜てしまう、〜ている、〜てください等
接续：动词原形 → て形
書く → 書いて
食べる → 食べて
する → して
割る → 割って
写 → 写了/写着（连接形）
吃 → 吃了/吃着（连接形）
做 → 做了/做着（连接形）
打碎 → 打碎了（连接形）
本题重点规则：
• 一类动词词尾「う・つ・る」→「って」
例：買う→買って、待つ→待って、割る→割って

所以：
割る（わる）→ 割って（わって）

这正是本题正确答案的关键。
〜てください（请...）
意思：礼貌地请求对方做某事
接续：动词て形 + ください
ゆっくり呼吸をしてください。
ここに名前を書いてください。
请慢慢呼吸。
请在这里写名字。
重点：
• 这是N5非常基础但非常重要的请求表达
• 语气比命令形柔和很多
• 结构一定是动词て形 + ください
• 呼吸する → 呼吸をして → 呼吸をしてください
〜ないでください（请不要...）
意思：礼貌地请求对方不要做某事
接续：动词ない形（去い）+ ないでください
ここで写真を撮らないでください。
急がないでください。ゆっくりでいいですよ。
请不要在这里拍照。
请不要着急。慢慢来就好。
重点：
• 是「〜てください」的否定形式
• 先把动词变成ない形，再把「ない」后面加「でください」
• 撮る → 撮らない → 撮らないでください
• 急ぐ → 急がない → 急がないでください
• 食べる → 食べない → 食べないでください
• する → しない → しないでください
• 来る → 来ない（こない）→ 来ないでください

N4 语法 LEVEL N4

〜とき（...的时候）
意思：表示时间、时机
接续：动词/形容词/名词 + とき
時間があるときに、読んでください。
日本に行ったとき、たくさん買い物をしました。
有时间的时候，请阅读。
去日本的时候，买了很多东西。
接续方式：
• 动词原形/た形 + とき
• い形容词 + とき
• な形容词/名词 + の + とき
〜てしまう（完成/遗憾）
意思：表示动作完成；表示遗憾、后悔、不由自主
接续：动词て形 + しまう
【完成义】
宿題をしてしまった。（作业做完了。）

【遗憾义】
財布を落としてしまった。（把钱包弄丢了。）
涙が出てしまった。（眼泪流出来了。）
强调动作完成

带有遗憾的感情
不由自主地流泪
两种用法：
1. 完成义：强调动作全部完成
2. 遗憾义：表示不如意的结果，带有遗憾、后悔、无奈的感情色彩

「しまう」和「しまいました」的区别：
• しまう：原形 / 简体，较普通、较口语，也可放进辞书里查到
例：割ってしまう（会弄碎 / 弄碎掉）
• しまいました：ました形 / 礼貌过去式，表示“已经……了”
例：割ってしまいました（弄碎了）

具体怎么变形：
しまう → しまいます → しまいました
第一步：把原形「しまう」变成ます形「しまいます」
第二步：把「ます」变成过去式「ました」→「しまいました」

为什么会这样：
• 「しまう」是一类动词，词尾是「う」
• 一类动词变ます形时：う段 → い段 + ます
• 所以：う → い + ます
• 结果就是：しまう → しまい + ます → しまいます
• 再变过去：しまいます → しまいました

整句也一样：
割ってしまう → 割ってしまいます → 割ってしまいました

所以本质区别有两个：
1. 时态不同：しまう = 非过去；しまいました = 过去
2. 语气不同：しまう = 简体；しまいました = 礼貌体

口语缩略形式：
• 出てしまう → 出ちゃう
• 出てしまった → 出ちゃった
• 食べてしまう → 食べちゃう

变形方法：
一类动词：書く → 書いて + しまう
二类动词：食べる → 食べて + しまう
三类动词：する → して + しまう
〜たほうがいい（最好...）
意思：表示建议，最好做某事
接续：动词た形 + ほうがいい
お金はあの箱に移したほうがいいですか。
早く寝たほうがいいです。
钱放到那个箱子里比较好吗？
你最好早点睡。
重点：
• 表示“这样做比较好、最好这样做”
• 先把动词变成た形，再接「ほうがいい」
• 移す → 移した → 移したほうがいい
• 句末加「ですか」时，整句就变成征求意见： "这样做比较好吗？"

为什么这里用「た」？
• 这里的「た」形式上是た形，但在这个句型里不单纯表示过去时间
• 你要把「〜たほうがいい」整个记成固定句型：做……比较好 / 最好做……
• 例如：早く寝たほうがいい = 最好早点睡；病院へ行ったほうがいい = 最好去医院
• 这里都不是“过去睡了比较好”“过去去了比较好”，而是在表示建议

对比理解：
• 薬を飲んだ。= 吃药了（这里的た，真的是过去）
• 薬を飲んだほうがいい。= 最好吃药（这里的た，是建议句型的一部分）

否定形式：
• 〜ないほうがいい = 最好不要……
• 例：夜はコーヒーを飲まないほうがいい。
〜く/になる（变得...）
意思：表示状态发生变化，"变得..."
接续：い形容词（去い）+ くなる ／ な形容词 + になる ／ 名词 + になる
天気が暖かくなりました。
部屋がきれいになりました。
彼は先生になりました。
天气变暖了。
房间变干净了。
他成为了老师。
重点：
• い形容词：去掉「い」+ くなる → 暖かい → 暖かくなる
• な形容词：词干 + になる → きれい → きれいになる
• 名词：名词 + になる → 先生 → 先生になる
• 「なる」本身是五段动词，可以进一步变形：なります（礼貌）、なった（过去）、なって（て形）等
• 注意与「〜くする/にする」（主动使之变化）的区别：なる是自然变化，する是人为改变
自動詞・他動詞（自动词 / 他动词）
意思：区分“自己发生变化”与“对对象施加动作”
接续：自动词常与「が」搭配；他动词常与「を」搭配
けがが治りました。
医者がけがを治しました。

人が大阪に移りました。
荷物を別の部屋に移しました。
伤好了。
医生把伤治好了。

人搬到大阪了。
把行李搬到了别的房间。
核心区别：
• 自動詞：动作、变化自己发生
• 他動詞：对别的对象做动作

常见搭配：
• 自动词：N が + 自动词
• 他动词：N を + 他动词

本次重点词对：
• 治る（なおる）= 自动词，病、伤自己好了
• 治す（なおす）= 他动词，把病、伤治好，把东西修好
• 移る（うつる）= 自动词，自己搬走、转移到别处
• 移す（うつす）= 他动词，把某物移过去

变形对照：
• 治る → 治って → 治った → 治らない
• 治す → 治して → 治した → 治さない
• 移る → 移って → 移った → 移らない
• 移す → 移して → 移した → 移さない

记忆提醒：
• 很多词有「る / す」成对现象：る常偏自动，す常偏他动
• 但这不是100%规则，最后还是要一个词一个词记

N3 语法 LEVEL N3

〜ている（正在...、...着）
意思：表示动作正在进行或状态持续
接续：动词て形 + いる
バズっている（正在成为热门话题）
発信してくれている（正在为大家发布）
雨が降っています（正在下雨）
正在成为热门话题
正在为大家发布
正在下雨
变形方法：
一类动词：書く → 書いて + いる
二类动词：食べる → 食べて + いる
三类动词：する → して + いる
〜てみる（试着做...）
意思：尝试做某事
接续：动词て形 + みる
読んでみてください（请试着读一下）
やってみる（试着做）
食べてみる（试着吃）
请试着读一下
试着做
试着吃
说明：みる本身是"看"的意思，作为补助动词表示"试着..."。
常见搭配：〜てみてください（请试着做...）
〜という（...的）
意思：表示前面的内容是后面名词的具体内容
接续：句子/短语 + という + 名词
3つの視点で注目です（有三个视角值得关注）
「田中」という人（叫田中的人）
有三个视角值得关注
叫田中的人
用法：用于解释说明、定义内容。
〜てくれる（为我做...）
意思：表示别人为我（们）做某事
接续：动词て形 + くれる
発信してくれている（为大家发布）
教えてくれました（为我教了...）
買ってくれる（为我买...）
正在为大家发布
为我教了...
为我买...
重要：表示恩惠关系，强调对方的善意。
变形：くれている = 正在为我（们）做...
〜のは〜だ（强调说明）
意思：把某一部分拿出来重点说明，相当于“……的是……”
接续：普通形 + のは + 名词/句子 + だ
淘汰されるのは誰か。
大切なのは行動することです。
被淘汰的是谁？
重要的是采取行动。
说明：「の」把前面的动作或状态名词化，再用「は」提出主题。文章标题里就是用这个句型强调“到底是谁会被淘汰”。
〜を意味する（意味着）
意思：表示“具有……含义”“意味着……”
接续：名词 + を + 意味する
「SaaSの死」はSIerの終わりを意味しません。
この数字は危機を意味する。
“SaaS之死”并不意味着SIer的终结。
这个数字意味着危机。
说明：「意味する」是比较书面的说法，常出现在说明文、评论文中。
〜によって（由于/被）
意思：可表示原因、手段，也可用于被动句中表示动作发出者
接续：名词 + によって
競合他社によって、市場から駆逐されるでしょう。
台風によって電車が止まった。
会被竞争对手公司赶出市场吧。
因台风电车停运了。
重要：这里不是“按照”，而是在被动句里表示“被谁……”。
〜こそ（正是）
意思：强烈强调前面的词，相当于“正是……才……”
接续：名词 + こそ
AIを味方に付けたユーザー企業こそが、真の競合となる。
今こそ変わるべきだ。
正是那些把AI变成助力的用户企业，才会成为真正的竞争对手。
现在正是应该改变的时候。
说明：语气很强，表示“不是别的，正是这个”。考试里常考强调作用。
〜における（在...中）
意思：书面语，表示“在……方面/在……场合中”
接续：名词 + における + 名词
この過渡期における摩擦を恐れず、進む。
現代社会における教育の役割。
不要害怕这一过渡期中的摩擦，继续前进。
现代社会中教育的作用。
对比：口语里常说「〜での」，书面文章更常用「〜における」。
〜ず（不...）
意思：书面语否定，等于「〜ないで」「〜なくて」的一部分用法
接续：动词ない形去ない + ず（但する→せず）
摩擦を恐れず、改革を進める。
何も言わずに帰った。
不惧摩擦，推进改革。
什么也没说就回去了。
重要：这是书面表达。特殊形式：する → せず。
〜からの（从...的）
意思：表示“从某处/某状态出发的……”
接续：名词 + からの + 名词
人月モデルからの脱却を完了させる。
故郷からの手紙。
完成从人月模式中的脱离。
来自故乡的信。
说明：这里的「から」不是单独结束，而是接「の」后修饰后面的名词。
〜こともある（也有时会...）
意思：表示有时会发生某种情况
接续：普通形 + こともある
真の競合となることもある。
失敗することもある。
也有可能成为真正的竞争对手。
也有失败的时候。
说明：比直接说「なる」语气更缓和，表示“存在这种可能性”。
〜てはならない（不可...）
意思：表示禁止，“不可以……”“不能……”
接续：动词て形 + はならない
忘れてはなりません。
ここで諦めてはならない。
不能忘记。
不可以在这里放弃。
对比：比「〜てはいけない」更书面、更郑重。
〜させる（使...完成）
意思：使役形，表示“让/使某人做某事”
接续：动词使役形
脱却を完了させる責任がある。
子どもに野菜を食べさせる。
有责任使脱离旧模式这件事完成。
让孩子吃蔬菜。
说明：「完了する」是“完成”，「完了させる」是“使其完成、把它做完”。这里强调主动推进结果达成。
〜道なのです（说明结论）
意思：用「のです」对前面的判断作解释说明，带有总结结论的语气
接续：普通形 + のです
それが、AI時代の新たなエコシステムで生き残る道なのです。
だから急ぐ必要があるのです。
那才是在AI时代的新生态系统中生存下去的道路。
所以才有必要着急。
说明：「のです」不是单纯的"是"，而是"这就是原因/结论/解释"。文章收尾很常见。
〜なくても（即使不...也...）
意思：表示让步条件，"即使不做某事也..."
接续：动词ない形（去い）+ なくても ／ い形容词（去い）+ くなくても ／ な形容词 + でなくても
急がなくても、まだ間に合いますよ。
高くなくても、いい物はあります。
完全でなくても、大丈夫です。
即使不着急，还来得及哦。
即使不贵，也有好东西。
即使不完美，也没关系。
重点：
• 动词：ない形去「い」+ くても → 急がない → 急がなくても
• い形容词：去「い」+ くなくても → 高い → 高くなくても
• な形容词/名词：+ でなくても → 完全 → 完全でなくても
• 后面常接「いい」「大丈夫」「かまわない」等表示"也没关系"的表达
• 与「〜ても」（即使...也）是同系列语法：食べても（即使吃了也）↔ 食べなくても（即使不吃也）
サ变名词 + する / をする
意思：很多动作性名词既能直接+する，也能用「名词 + を + する」
接续：サ变名词 + する ／ 名词 + を + する
呼吸する。
呼吸をする。
勉強する。
けがをする。
呼吸。
进行呼吸。
学习。
受伤。
重点：
• 有些词更常直接说：勉強する、運動する、練習する
• 有些词更常说「をする」：けがをする、深呼吸をする、咳をする
• 呼吸两种都能说：呼吸する / 呼吸をする
• 所以它可以变成：
  呼吸する → 呼吸して → 呼吸してください
  呼吸をする → 呼吸をして → 呼吸をしてください
• 句子里出现「を」不是多出来，而是说话人选了「名词 + をする」这个表达方式

为什么会有两种说法？
• 因为很多汉字动作名词本身既可以直接サ变，也可以先当普通名词，再配「をする」
• 所以：呼吸する / 呼吸をする，这两种都成立

一步一步变形：
• 呼吸する → 呼吸して → 呼吸してください
• 呼吸をする → 呼吸をして → 呼吸をしてください

学习建议：
• 遇到这类词，先记住常见固定搭配
• 例如：けがをする、深呼吸をする、呼吸をする
助词「で」（范围 / 场所 / 领域）
意思：表示动作发生的场所，也可表示范围、领域、手段
接续：名词 + で
オープンソースで数十年間見過ごされていた。
教室で勉強する。
日本語で話す。
在开源领域中几十年来一直被忽视。
在教室学习。
用日语说。
重点：
• N5基础助词，但非常重要
• 「で」可以表示动作场所：教室で勉強する
• 也可以表示手段：日本語で話す
• 这里「オープンソースで」更接近“在开源这一范围/环境中”
受身形（〜される / 〜されていた）
意思：表示“被……”
接续：动词受身形
見過ごされていた。
発見された。
先生にほめられた。
一直被忽视着。
被发现了。
被老师表扬了。
重点：
• 受身形就是“被动形”
• 見過ごす → 見過ごされる = 被忽视
• 再加「ている」表示状态持续：見過ごされている = 正处于被忽视的状态
• 过去形式「ていた」表示过去一段时间持续如此：見過ごされていた = 过去一直被忽视
〜から〜へ（从...到...）
意思：表示变化、移动、转变的起点和终点
接续：名词 + から + 名词 + へ
人間の補助から自律型従業員へ進化する。
家から学校へ行く。
从人类辅助进化到自律型员工。
从家去学校。
重点：
• 「から」表示起点，“从……”
• 「へ」表示方向、目标，“向……/到……”
• 在标题和说明文里，这个结构常用来表示概念上的转变，不一定是实际移动
数量词 + 以上
意思：表示“……以上”“不少于……”
接续：数量词 + 以上
500以上のゼロデイバグ。
3人以上が必要です。
500个以上的零日漏洞。
需要3人以上。
重点：
• 接在数字后面，表示下限
• 500以上 = 500或更多
• 如果后面还要修饰名词，可以接「の」：500以上のバグ
〜的に（...地 / 从...角度）
意思：把「〜的」这类词变成副词，表示“……地”
接续：名词/词干 + 的に
AIが自律的に発見・修正した。
具体的に説明する。
AI自主地进行了发现和修正。
具体地说明。
重点：
• 「自律的」是形容动词性质的词
• 加「に」后变成副词：自律的に = 自主地
• 这一类词在说明文、新闻、商业文章中很常见，如：一般的に、基本的に、具体的に
