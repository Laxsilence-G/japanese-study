日语语法笔记 - JLPT N3备考

开始日期：2026年3月17日 | 目标考试：2026年7月JLPT N3

N5 语法 LEVEL N5

问候语的时间区分
意思：根据时间段使用不同的问候语
接续：独立使用，无需接续
おはようございます（早晨）→ こんにちは（白天）→ こんばんは（晚上）
早上好 → 你好 → 晚上好
重要：日语问候语严格区分时间段，用错会显得很奇怪。
礼貌体与简体
意思：根据对象选择礼貌程度
接续：独立使用
おはようございます（礼貌）←→ おはよう（随意）
早上好（礼貌）←→ 早（随意）
规则：对长辈、上司、陌生人使用礼貌体；对朋友、家人、晚辈可以使用简体。
动词分类（三类）
意思：日语动词分为三类，变形规则不同
接续：动词原形
一类动词（五段动词）：書く、飲む、話す、買う
二类动词（一段动词）：食べる、見る、起きる、寝る
三类动词（不规则动词）：する、来る
一类：词尾在う段，变形时词尾在五段变化
二类：词尾是る，る前在い/え段
三类：只有两个，变形不规则
判断方法：
1. 词尾不是る → 一类动词
2. 词尾是る，る前在い/え段 → 二类动词
3. する、来る → 三类动词
注意：走る、帰る、入る、知る、蹴る等是一类动词的例外！
动词ます形（礼貌体）
意思：表示礼貌的动词形式
接续：动词原形 → ます形
一类动词：う段 → い段 + ます
書く → 書きます、飲む → 飲みます、話す → 話します

二类动词：去掉る + ます
食べる → 食べます、見る → 見ます、起きる → 起きます

三类动词：特殊变形
する → します、来る → 来ます（きます）
一类：词尾う段变い段
二类：去掉る
三类：特殊记忆
记忆口诀：
一类：う段 → い段 + ます（く→き、む→み、す→し...）
二类：去掉る，加上ます
三类：する→します、来る→来ます（きます）
ます形の四种变化
意思：ます形的肯定、否定、过去、过去否定
接续：ます形基础
形式 变化 意思 例子
肯定 〜ます 做... 書きます（写）
否定 〜ません 不做... 書きません（不写）
过去 〜ました 做了... 書きました（写了）
过去否定 〜ませんでした 没做... 書きませんでした（没写）
记忆口诀：
ます变ません（否定）
ます变ました（过去）
ません + でした（过去否定）
终助词「ね」（寻求共鸣、确认）
意思：表示确认、征求同意、感叹
接续：句子 + ね
すごいね（好厉害啊）
いい天気ですね（好天气啊）
分かるね？（懂了吧？）
そうですね（是啊）
表示感叹
表示感叹
表示确认
表示同意
「ね」的三大作用：
1. 确认：分かるね？（懂了吧？）- 确认对方是否理解
2. 感叹：いい天気ですね（好天气啊）- 表达情感
3. 征求同意：そうですね（是啊）- 寻求共鸣

用法：
• い形容词：直接加ね → すごいね
• な形容词/名词：加だね → 静かだね、学生だね
• 动词：简体加ね → 分かるね、行くね
• 礼貌体：加ですね → すごいですね、分かりますね
い形容词的用法
意思：以"い"结尾的形容词，可直接修饰名词或作谓语
接续：い形容词 + 名词 / 句尾
修饰名词：
すごい人（厉害的人）
おいしい料理（好吃的菜）

作谓语：
この映画はすごい（这部电影很厉害）
すごいね（好厉害啊）
すごいですね（真厉害啊 - 礼貌）
すごい修饰人
おいしい修饰料理

すごい作谓语（简体）
加终助词ね
加です表示礼貌
重要：い形容词作谓语时不需要加"だ"！
✓ すごい（正确）
✗ すごいだ（错误）

礼貌形：い形容词 + です
✓ すごいです（正确）
✓ おいしいです（正确）
助词「が」（主语标记）
意思：提示动作、状态的主体；回答“谁/什么”时常用
接续：名词 + が + 动词/形容词
弟がこれを割ってしまいました。
猫がいます。
何が好きですか。
弟弟把这个弄碎了。
有猫。
你喜欢什么？
重点：
• 「が」前面的词，往往是动作的执行者或状态的主体
• 在本句里，弟が = “弟弟”是“打碎”这个动作的执行者
• 不要和提示主题的「は」混淆：
弟は学生です（说到弟弟，他是学生）
弟が割りました（是弟弟打碎的）
助词「を」（宾语标记）
意思：表示动作直接作用的对象
接续：名词 + を + 他动词
弟がこれを割ってしまいました。
本を読む。
水を飲みます。
弟弟把这个弄碎了。
读书。
喝水。
重点：
• 「を」前面的词，是动作直接影响到的对象
• 本句中 これを = “这个”就是被打碎的东西
• 发音常接近“o”，但写作固定是「を」
助词「に」（目标点 / 着落点）
意思：表示动作到达的位置、附着点、写入的位置
接续：名词（地点） + に
ここに名前を書いてください。
紙に字を書きます。
请在这里写名字。
在纸上写字。
重点：
• 这里的「に」表示写到哪里
• 「ここに身長を書いてください」里，「ここに」就是“在这里 / 写在这里”
• 可以把它理解成动作落下去的地方、填写的位置
• 不要和「で」混淆：に偏向目标点，で偏向动作发生的场所
动词て形（て-form）
意思：连接后续语法，如〜てしまう、〜ている、〜てください等
接续：动词原形 → て形
書く → 書いて
食べる → 食べて
する → して
割る → 割って
写 → 写了/写着（连接形）
吃 → 吃了/吃着（连接形）
做 → 做了/做着（连接形）
打碎 → 打碎了（连接形）
本题重点规则：
• 一类动词词尾「う・つ・る」→「って」
例：買う→買って、待つ→待って、割る→割って

所以：
割る（わる）→ 割って（わって）

这正是本题正确答案的关键。
〜てください（请...）
意思：礼貌地请求对方做某事
接续：动词て形 + ください
ゆっくり呼吸をしてください。
ここに名前を書いてください。
请慢慢呼吸。
请在这里写名字。
重点：
• 这是N5非常基础但非常重要的请求表达
• 语气比命令形柔和很多
• 结构一定是动词て形 + ください
• 呼吸する → 呼吸をして → 呼吸をしてください
〜ないでください（请不要...）
意思：礼貌地请求对方不要做某事
接续：动词ない形（去い）+ ないでください
ここで写真を撮らないでください。
急がないでください。ゆっくりでいいですよ。
请不要在这里拍照。
请不要着急。慢慢来就好。
重点：
• 是「〜てください」的否定形式
• 先把动词变成ない形，再把「ない」后面加「でください」
• 撮る → 撮らない → 撮らないでください
• 急ぐ → 急がない → 急がないでください
• 食べる → 食べない → 食べないでください
• する → しない → しないでください
• 来る → 来ない（こない）→ 来ないでください
〜たい（想要...）
意思：表示说话人想做某事
接续：动词ます形去ます + たい
日本へ行きたいです。
この町で子どもを育てたいと思っています。
想去日本。
我正想着想在这个城镇养育孩子。
重点：
• 先把动词变成ます形词干，再加「たい」
• 育てます → 育てたい
• 「たい」在性质上接近い形容词，所以可以说「育てたくない」「育てたかった」
• 这是表示“我想做……”的基础句型
助词「から」（从...）
意思：表示起点、出发点，常译为“从……”
接续：名词 + から
ここから森林が見えます。
今からメールを送信します。
从这里能看见森林。
现在开始发送邮件。
重点：
• 「から」表示动作、观察的起点
• 这里「ここから」= 从这里；「今から」= 从现在开始
• 常与「まで」对比：から = 从……；まで = 到……为止
助词「で」（手段 / 工具）
意思：表示“用……”“通过……”，说明做动作所使用的工具、材料、方法
接续：名词 + で + 动词
このタオルで体をふいてください。
はしでご飯を食べます。
日本語で話してください。
请用这条毛巾擦身体。
用筷子吃饭。
请用日语说。
重点：
• 这里的「で」不是地点，而是手段、工具
• 「タオルで」= 用毛巾；「はしで」= 用筷子；「日本語で」= 用日语
• 要和地点助词「で」区分：
学校で勉強する（在学校学习）= 地点
ペンで書く（用笔写）= 工具
助词「まで」（到...为止）
意思：表示终点、界限，常译为“到……为止”“到……”
接续：名词 + まで
ここから市役所までどのくらいですか。
駅まで歩きます。
三時まで勉強します。
从这里到市政府有多远？
走到车站。
学习到三点。
重点：
• 「から」表示起点，「まで」表示终点：から〜まで = 从……到……
• 不仅能表示地点终点，也能表示时间终点
• 「市役所までの距離」里，「まで」后面加「の」来修饰名词，意思是“到市役所为止的距离”
〜ても（即使...也...）
意思：表示让步，“即使……也……”
接续：动词て形 + も ／ い形容词去い + くても ／ な形容词・名词 + でも
雨が降っても、行きます。
熱が下がっても、薬を飲んでください。
高くても、必要なら買います。
即使下雨也去。
即使退烧了，也请吃药。
即使贵，只要有需要也会买。
重点：
• 表示前项成立了，后项仍然不变
• 和「〜たら」不同，「〜ても」不是单纯条件，而是“即使如此也……”
〜たら（如果...的话）
意思：表示条件，“如果……的话”
接续：动词た形 + ら ／ い形容词かった + ら ／ 名词・な形容词 + だったら
何をあげたら、喜ぶでしょうか。
時間があったら、行きます。
安かったら、買います。
如果送什么的话，他会高兴呢？
如果有时间的话，我就去。
如果便宜的话，我就买。
重点：
• 很常见的条件表达
• 本题里是“如果送弟弟什么，他会高兴呢”
• 不要和表示原因的「から」混淆
授受动词「あげる／くれる」
意思：表示“给”，但要注意方向
接续：人に + 物を + あげる ／ 人が（私に）+ 物を + くれる
私は弟に本をあげました。
友達が私に本をくれました。
何をあげたら、弟は喜ぶでしょうか。
我给弟弟书了。
朋友给了我一本书。
如果送弟弟什么，他会高兴呢？
重点：
• あげる：我/我方给别人
• くれる：别人给我/我方
• 方向错了，句子意思就错了
〜ておく（事先...；先...）
意思：表示为了之后方便，事先做某事
接续：动词て形 + おく
明日の会議のために、資料を読んでおきます。
ドアを開けておいてください。
持っておく。
为了明天的会议，先把资料读好。
请先把门开着。
先拿着/预先准备好。
重点：
• 口语里常缩成「〜とく」：読んどく、持っとく
• 第9题里「持っとく」如果放进句子，会变成“我先拿着/先准备着”，不如「持ってく」自然

N4 语法 LEVEL N4

〜とき（...的时候）
意思：表示时间、时机
接续：动词/形容词/名词 + とき
時間があるときに、読んでください。
日本に行ったとき、たくさん買い物をしました。
有时间的时候，请阅读。
去日本的时候，买了很多东西。
接续方式：
• 动词原形/た形 + とき
• い形容词 + とき
• な形容词/名词 + の + とき
〜てしまう（完成/遗憾）
意思：表示动作完成；表示遗憾、后悔、不由自主
接续：动词て形 + しまう
【完成义】
宿題をしてしまった。（作业做完了。）

【遗憾义】
財布を落としてしまった。（把钱包弄丢了。）
涙が出てしまった。（眼泪流出来了。）
携帯を床に落としてしまいました。（我不小心把手机掉到地板上了。）
强调动作完成

带有遗憾的感情
不由自主地流泪
不小心把手机掉到了地板上
两种用法：
1. 完成义：强调动作全部完成
2. 遗憾义：表示不如意的结果，带有遗憾、后悔、无奈的感情色彩

「しまう」和「しまいました」的区别：
• しまう：原形 / 简体，较普通、较口语，也可放进辞书里查到
例：割ってしまう（会弄碎 / 弄碎掉）
• しまいました：ました形 / 礼貌过去式，表示“已经……了”
例：割ってしまいました（弄碎了）

具体怎么变形：
しまう → しまいます → しまいました
第一步：把原形「しまう」变成ます形「しまいます」
第二步：把「ます」变成过去式「ました」→「しまいました」

为什么会这样：
• 「しまう」是一类动词，词尾是「う」
• 一类动词变ます形时：う段 → い段 + ます
• 所以：う → い + ます
• 结果就是：しまう → しまい + ます → しまいます
• 再变过去：しまいます → しまいました

整句也一样：
割ってしまう → 割ってしまいます → 割ってしまいました

所以本质区别有两个：
1. 时态不同：しまう = 非过去；しまいました = 过去
2. 语气不同：しまう = 简体；しまいました = 礼貌体

口语缩略形式：
• 出てしまう → 出ちゃう
• 出てしまった → 出ちゃった
• 食べてしまう → 食べちゃう

补充：
• 〜てしまい 是「〜てしまいます」去掉「ます」后的连用形式，常用于连接后句，不能单独作为完整句子结束。
• 例如：携帯を床に落としてしまい、画面が割れました。（不小心把手机掉到地上，屏幕碎了。）

四种形式的区别：
• 〜てしまう：原形 / 简体 / 非过去。可表示将来、习惯、一般叙述，也可用于辞书形说明。
例：大事な資料をなくしてしまうことがある。（有时会不小心把重要资料弄丢。）
• 〜てしまい：连用形。主要用于连接后句、书面表达、句中停顿，通常不能单独结束整句。
例：宿題を忘れてしまい、先生に注意された。（忘了作业，结果被老师提醒了。）
• 〜てしまった：简体过去式。表示“已经……了 / 不小心……了”，语气较普通、较口语。
例：財布を落としてしまった。（我把钱包弄丢了。）
• 〜てしまいました：礼貌过去式。意思和「〜てしまった」基本相同，但更礼貌，适合正式场合或对人说话。
例：パスポートをなくしてしまいました。（我把护照弄丢了。）

一句话总结：
• しまう = 原形
• しまい = 连用形（接后句）
• しまった = 简体过去
• しまいました = 礼貌过去

它们之间怎么变形：
• 第一步：先做出「动词て形 + しまう」这个基本形式。
例：落とす → 落として → 落としてしまう
• 第二步：如果要连接后句，把「しまう」变成连用形「しまい」。
例：落としてしまう → 落としてしまい
• 第三步：如果要变成简体过去，把「しまう」变成「しまった」。
例：落としてしまう → 落としてしまった
• 第四步：如果要变成礼貌过去，先「しまう → しまいます」，再「しまいます → しまいました」。
例：落としてしまう → 落としてしまいます → 落としてしまいました

核心原因：
• 「しまう」本身是一个一类动词。
• 一类动词词尾「う」变连用形时，变成「い」：しまう → しまい
• 一类动词过去简体常见变化：う/つ/る → った，所以：しまう → しまった
• 一类动词礼貌形：う段 → い段 + ます，所以：しまう → しまいます → しまいました

变形方法：
一类动词：書く → 書いて + しまう
二类动词：食べる → 食べて + しまう
三类动词：する → して + しまう
〜たほうがいい（最好...）
意思：表示建议，最好做某事
接续：动词た形 + ほうがいい
お金はあの箱に移したほうがいいですか。
早く寝たほうがいいです。
钱放到那个箱子里比较好吗？
你最好早点睡。
重点：
• 表示“这样做比较好、最好这样做”
• 先把动词变成た形，再接「ほうがいい」
• 移す → 移した → 移したほうがいい
• 句末加「ですか」时，整句就变成征求意见： "这样做比较好吗？"

为什么这里用「た」？
• 这里的「た」形式上是た形，但在这个句型里不单纯表示过去时间
• 你要把「〜たほうがいい」整个记成固定句型：做……比较好 / 最好做……
• 例如：早く寝たほうがいい = 最好早点睡；病院へ行ったほうがいい = 最好去医院
• 这里都不是“过去睡了比较好”“过去去了比较好”，而是在表示建议

对比理解：
• 薬を飲んだ。= 吃药了（这里的た，真的是过去）
• 薬を飲んだほうがいい。= 最好吃药（这里的た，是建议句型的一部分）

否定形式：
• 〜ないほうがいい = 最好不要……
• 例：夜はコーヒーを飲まないほうがいい。
〜く/になる（变得...）
意思：表示状态发生变化，"变得..."
接续：い形容词（去い）+ くなる ／ な形容词 + になる ／ 名词 + になる
天気が暖かくなりました。
部屋がきれいになりました。
彼は先生になりました。
天气变暖了。
房间变干净了。
他成为了老师。
重点：
• い形容词：去掉「い」+ くなる → 暖かい → 暖かくなる
• な形容词：词干 + になる → きれい → きれいになる
• 名词：名词 + になる → 先生 → 先生になる
• 「なる」本身是五段动词，可以进一步变形：なります（礼貌）、なった（过去）、なって（て形）等
• 注意与「〜くする/にする」（主动使之变化）的区别：なる是自然变化，する是人为改变
自動詞・他動詞（自动词 / 他动词）
意思：区分“自己发生变化”与“对对象施加动作”
接续：自动词常与「が」搭配；他动词常与「を」搭配
けがが治りました。
医者がけがを治しました。

人が大阪に移りました。
荷物を別の部屋に移しました。
伤好了。
医生把伤治好了。

人搬到大阪了。
把行李搬到了别的房间。
核心区别：
• 自動詞：动作、变化自己发生
• 他動詞：对别的对象做动作

常见搭配：
• 自动词：N が + 自动词
• 他动词：N を + 他动词

本次重点词对：
• 治る（なおる）= 自动词，病、伤自己好了
• 治す（なおす）= 他动词，把病、伤治好，把东西修好
• 移る（うつる）= 自动词，自己搬走、转移到别处
• 移す（うつす）= 他动词，把某物移过去

变形对照：
• 治る → 治って → 治った → 治らない
• 治す → 治して → 治した → 治さない
• 移る → 移って → 移った → 移らない
• 移す → 移して → 移した → 移さない

记忆提醒：
• 很多词有「る / す」成对现象：る常偏自动，す常偏他动
• 但这不是100%规则，最后还是要一个词一个词记
〜と思っている
意思：表示心里一直这样想；有这样的打算、计划
接续：普通形 + と思っている
この町で子どもを育てたいと思っている。
来年日本へ行こうと思っています。
我正想着要在这个城镇养育孩子。
我正打算明年去日本。
重点：
• 「と思う」是“我想、我觉得”
• 「と思っている」更强调这个想法已经持续一段时间，或表示计划、打算
• 本题里不是突然一瞬间想到，而是“心里一直有这个打算”
〜でしょうか
意思：礼貌地提问，语气比「ですか」更委婉
接续：名词 / な形容词 / 普通形 + でしょうか
文字の色を変えることは可能でしょうか。
これは正しいでしょうか。
可以改变文字的颜色吗？
这个是正确的吗？
重点：
• 「でしょうか」常用于客服、商务、礼貌询问场景
• 比直接说「ですか」更柔和、更客气
• 「可能でしょうか」= “可以吗 / 是否可行呢”
自動詞「見える」的用法
意思：表示“能看见”“映入眼帘”
接续：名词 + が + 見える
ここから森林が見えます。
窓から海が見えます。
从这里能看见森林。
从窗户能看见海。
重点：
• 「見える」是自动词，常搭配「が」
• 不说「森林を見えます」✗，而说「森林が見えます」✓
• 和「見る」区别：見る = 主动去看；見える = 自然看得见
〜こと（把动作名词化）
意思：把前面的动作、行为变成"这件事"
接续：动词普通形 + こと
文字の色を変えることは可能でしょうか。
日本語を勉強することは楽しいです。
改变文字颜色这件事可以吗？
学日语这件事很开心。
重点：
• 「変える」本来是动词"改变"
• 变成「変えること」后，就变成"改变这件事"
• 所以「変えることは可能でしょうか」= "做这个改变可以吗？"
〜た後（た形...之后）
意思：表示做完某事之后，强调动作完成的时间点
接续：动词た形 + 後（+は）
接続情報を入手した後は確認してください。
食べた後は寝ないでください。
仕事が終わった後は飲みに行きましょう。
获取连接信息后，请确认。
吃完后请不要睡觉。
工作结束后去喝一杯吧。
重点：
• 先把动词变成た形（过去式），再加「後（あと）」
• 入手する → 入手した → 入手した後
• 食べる → 食べた → 食べた後
• 加「は」表示强调主题：入手した後は = 做完这件事之后（要注意...）

与「〜てから」的区别：
• 〜た後：强调"做完...之后"这个时间点
• 〜てから：强调动作的先后顺序（先做A，再做B）
例：食べてから寝る（吃完再睡） vs 食べた後は寝ないで（吃完后不要睡）

常见用法：
• 〜た後で（...之后）
• 〜た後は（...之后要注意/要...）
• その後（そのご/そのあと）= 之后
い形容词「〜くて」
意思：把前后内容连接起来，可表示并列、原因、状态连接
接续：い形容词去「い」 + くて
景色が素晴らしくて、感動しました。
この店は安くておいしいです。
怖くて眠れませんでした。
风景很棒，非常感动。
这家店又便宜又好吃。
因为害怕，没能睡着。
重点：
• い形容词不能直接接「て」，要先把「い」变成「くて」
• 素晴らしい → 素晴らしくて
• 用法有两大类：
1. 并列：安くておいしい（又便宜又好吃）
2. 原因：怖くて眠れない（因为害怕睡不着）
• 这类题里常常通过前后语义判断后句应该接什么感情或结果
连体修饰（普通形 / 句子 + 名词）
意思：用前面的词或句子直接修饰后面的名词，相当于“……的……”
接续：普通形 + 名词 ／ 名词 + の + 名词
以前誰かが使っていた車。
旅行に持っていく物。
方法を思いついた人。
以前有人用过的车。
带去旅行的东西。
想到办法的人。
重点：
• 日语里，修饰名词的内容放在名词前面
• 不需要像中文那样一定加“的”
• 例如：
以前誰かが使っていた + 車 = 以前有人用过的车
持っていく + 物 = 要带去的东西
思いついた + 人 = 想出来的人
• 这是阅读和词汇题都非常高频的结构
い形容词过去式「〜かった」
意思：表示过去“很……”“曾经……”
接续：い形容词去「い」 + かった
この前はくやしかったです。
昨日は寒かったです。
子どものころ、この道は長かった。
上次很懊恼。
昨天很冷。
小时候，这条路很长。
重点：
• い形容词过去式：去「い」+ かった
• くやしい → くやしかった
• うれしい → うれしかった
• いい比较特殊：いい → よかった
• 不要说 ✗ くやしいでした，正确是 ✓ くやしかったです
〜ので（因为...）
意思：表示原因、理由，语气比「から」更客观、更柔和
接续：普通形 + ので ／ な形容词・名词 + な + ので
今回は勝てたので、本当にうれしいです。
坂道なので、歩くと疲れます。
静かなので、ここで勉強します。
因为这次赢了，所以真的很开心。
因为是坡路，所以走路会累。
因为安静，所以在这里学习。
重点：
• 「ので」也是“因为”，但语气通常比「から」更柔和、更说明事实
• 动词：勝てたので
• い形容词：寒いので
• な形容词/名词：静かなので、雨なので
• JLPT很喜欢考「から / ので」的细微语气区别
な形容词 + に（副词化）
意思：把な形容词变成副词，表示“……地”
接续：な形容词词干 + に
静かに話してください。
部屋をきれいにします。
本田さんたちは部屋からそっと出ていった。
请安静地说话。
把房间弄干净。
本田他们悄悄地从房间出去了。
重点：
• な形容词修饰名词时：静かな部屋
• な形容词修饰动词时：静かに話す
• JLPT常把「静かに」「きれいに」和普通副词一起放进选项里考你区分
• 但要注意：有时更自然的不一定是单纯的副词化，而是像「そっと」这种本身就是副词的词
〜より（比较基准）
意思：表示比较的对象，常译为“比……”
接续：名词 + より
今年はりんごの値段が去年より高いです。
今日は昨日より寒いです。
今年苹果的价格比去年高。
今天比昨天冷。
重点：
• 「AよりB」里，「より」前面是比较基准
• 去年より = 比去年；先生より = 比老师；これより = 比这个
• JLPT经常把它放在价格、数量、温度比较句里考
• 本题「去年より減少した」意思就是“比去年减少了”
〜ように言う / 頼む
意思：表示转达命令、请求、要求，常译为“让……”“吩咐……要……”
接续：动词辞书形 / ない形 + ように + 言う / 頼む / お願いする
医者から毎日運動するように言われました。
母は妹に部屋の掃除をするように言いました。
忘れないように頼みました。
被医生告知要每天运动。
妈妈对妹妹说要打扫房间。
我拜托了对方不要忘记。
重点：
• 这不是单纯的“像……一样”，而是表示内容要求
• 常和「言う・頼む・お願いする・言われる」一起出现
• 「運動するように言われた」= 被告知要运动
• 和「〜てほしい」有点接近，但「ように言う」更像“转达要求/指示”
〜か（疑问小句 / 间接疑问）
意思：把带疑问的内容整个当成一句话中的一部分
接续：普通形 + か
お金を稼ぐことがどれだけ大変か、わかった。
どこへ行くか、まだ決めていません。
何が必要か、教えてください。
我明白了挣钱有多辛苦。
还没决定去哪里。
请告诉我需要什么。
重点：
• 这里的「か」不是句末问别人，而是把“疑问内容”包起来
• 「どれだけ大変か」= “有多辛苦” 这一整块内容
• JLPT排序题很爱考这种“疑问词 + か”结构

N3 语法 LEVEL N3

〜ている（正在...、...着）
意思：表示动作正在进行或状态持续
接续：动词て形 + いる
バズっている（正在成为热门话题）
発信してくれている（正在为大家发布）
雨が降っています（正在下雨）
正在成为热门话题
正在为大家发布
正在下雨
变形方法：
一类动词：書く → 書いて + いる
二类动词：食べる → 食べて + いる
三类动词：する → して + いる
〜てみる（试着做...）
意思：尝试做某事
接续：动词て形 + みる
読んでみてください（请试着读一下）
やってみる（试着做）
食べてみる（试着吃）
请试着读一下
试着做
试着吃
说明：みる本身是"看"的意思，作为补助动词表示"试着..."。
常见搭配：〜てみてください（请试着做...）
〜という（...的）
意思：表示前面的内容是后面名词的具体内容
接续：句子/短语 + という + 名词
3つの視点で注目です（有三个视角值得关注）
「田中」という人（叫田中的人）
有三个视角值得关注
叫田中的人
用法：用于解释说明、定义内容。
〜てくれる（为我做...）
意思：表示别人为我（们）做某事
接续：动词て形 + くれる
発信してくれている（为大家发布）
教えてくれました（为我教了...）
買ってくれる（为我买...）
正在为大家发布
为我教了...
为我买...
重要：表示恩惠关系，强调对方的善意。
变形：くれている = 正在为我（们）做...
〜のは〜だ（强调说明）
意思：把某一部分拿出来重点说明，相当于“……的是……”
接续：普通形 + のは + 名词/句子 + だ
淘汰されるのは誰か。
大切なのは行動することです。
被淘汰的是谁？
重要的是采取行动。
说明：「の」把前面的动作或状态名词化，再用「は」提出主题。文章标题里就是用这个句型强调“到底是谁会被淘汰”。
〜を意味する（意味着）
意思：表示“具有……含义”“意味着……”
接续：名词 + を + 意味する
「SaaSの死」はSIerの終わりを意味しません。
この数字は危機を意味する。
“SaaS之死”并不意味着SIer的终结。
这个数字意味着危机。
说明：「意味する」是比较书面的说法，常出现在说明文、评论文中。
〜によって（由于/被）
意思：可表示原因、手段，也可用于被动句中表示动作发出者
接续：名词 + によって
競合他社によって、市場から駆逐されるでしょう。
台風によって電車が止まった。
会被竞争对手公司赶出市场吧。
因台风电车停运了。
重要：这里不是“按照”，而是在被动句里表示“被谁……”。
〜こそ（正是）
意思：强烈强调前面的词，相当于“正是……才……”
接续：名词 + こそ
AIを味方に付けたユーザー企業こそが、真の競合となる。
今こそ変わるべきだ。
正是那些把AI变成助力的用户企业，才会成为真正的竞争对手。
现在正是应该改变的时候。
说明：语气很强，表示“不是别的，正是这个”。考试里常考强调作用。
〜における（在...中）
意思：书面语，表示“在……方面/在……场合中”
接续：名词 + における + 名词
この過渡期における摩擦を恐れず、進む。
現代社会における教育の役割。
不要害怕这一过渡期中的摩擦，继续前进。
现代社会中教育的作用。
对比：口语里常说「〜での」，书面文章更常用「〜における」。
〜ず（不...）
意思：书面语否定，等于「〜ないで」「〜なくて」的一部分用法
接续：动词ない形去ない + ず（但する→せず）
摩擦を恐れず、改革を進める。
何も言わずに帰った。
不惧摩擦，推进改革。
什么也没说就回去了。
重要：这是书面表达。特殊形式：する → せず。
〜からの（从...的）
意思：表示“从某处/某状态出发的……”
接续：名词 + からの + 名词
人月モデルからの脱却を完了させる。
故郷からの手紙。
完成从人月模式中的脱离。
来自故乡的信。
说明：这里的「から」不是单独结束，而是接「の」后修饰后面的名词。
〜こともある（也有时会...）
意思：表示有时会发生某种情况
接续：普通形 + こともある
真の競合となることもある。
失敗することもある。
也有可能成为真正的竞争对手。
也有失败的时候。
说明：比直接说「なる」语气更缓和，表示“存在这种可能性”。
〜てはならない（不可...）
意思：表示禁止，“不可以……”“不能……”
接续：动词て形 + はならない
忘れてはなりません。
ここで諦めてはならない。
不能忘记。
不可以在这里放弃。
对比：比「〜てはいけない」更书面、更郑重。
〜させる（使...完成）
意思：使役形，表示“让/使某人做某事”
接续：动词使役形
脱却を完了させる責任がある。
子どもに野菜を食べさせる。
有责任使脱离旧模式这件事完成。
让孩子吃蔬菜。
说明：「完了する」是“完成”，「完了させる」是“使其完成、把它做完”。这里强调主动推进结果达成。
〜道なのです（说明结论）
意思：用「のです」对前面的判断作解释说明，带有总结结论的语气
接续：普通形 + のです
それが、AI時代の新たなエコシステムで生き残る道なのです。
だから急ぐ必要があるのです。
那才是在AI时代的新生态系统中生存下去的道路。
所以才有必要着急。
说明：「のです」不是单纯的"是"，而是"这就是原因/结论/解释"。文章收尾很常见。
〜なくても（即使不...也...）
意思：表示让步条件，"即使不做某事也..."
接续：动词ない形（去い）+ なくても ／ い形容词（去い）+ くなくても ／ な形容词 + でなくても
急がなくても、まだ間に合いますよ。
高くなくても、いい物はあります。
完全でなくても、大丈夫です。
即使不着急，还来得及哦。
即使不贵，也有好东西。
即使不完美，也没关系。
重点：
• 动词：ない形去「い」+ くても → 急がない → 急がなくても
• い形容词：去「い」+ くなくても → 高い → 高くなくても
• な形容词/名词：+ でなくても → 完全 → 完全でなくても
• 后面常接「いい」「大丈夫」「かまわない」等表示"也没关系"的表达
• 与「〜ても」（即使...也）是同系列语法：食べても（即使吃了也）↔ 食べなくても（即使不吃也）
サ变名词 + する / をする
意思：很多动作性名词既能直接+する，也能用「名词 + を + する」
接续：サ变名词 + する ／ 名词 + を + する
呼吸する。
呼吸をする。
勉強する。
けがをする。
呼吸。
进行呼吸。
学习。
受伤。
重点：
• 不是所有名词都能直接 + する
• 能直接构成三类动词的，通常是表示动作、行为、过程、变化的サ变名词
• 常见能直接 + する：勉強する、運動する、練習する、旅行する、電話する、入社する、共有する、転送する
• 有些词更自然说「名词 + を + する」：けがをする、深呼吸をする、咳をする
• 有些词两种都能说，但平时要以常见搭配为准：呼吸する / 呼吸をする、勉強する / 勉強をする
• 普通事物名词、人、地点等通常不能直接 + する：本する ×、学生する ×、日本する ×、水する ×
• 所以判断时不要自己随便造，最安全的方法是：查词典标记（名・サ変 / 名・スル）+ 记固定搭配

• 有些词更常直接说：勉強する、運動する、練習する
• 有些词更常说「をする」：けがをする、深呼吸をする、咳をする
• 呼吸两种都能说：呼吸する / 呼吸をする
• 所以它可以变成：
  呼吸する → 呼吸して → 呼吸してください
  呼吸をする → 呼吸をして → 呼吸をしてください
• 句子里出现「を」不是多出来，而是说话人选了「名词 + をする」这个表达方式

为什么会有两种说法？
• 因为很多汉字动作名词本身既可以直接サ变，也可以先当普通名词，再配「をする」
• 所以：呼吸する / 呼吸をする，这两种都成立

一步一步变形：
• 呼吸する → 呼吸して → 呼吸してください
• 呼吸をする → 呼吸をして → 呼吸をしてください

学习建议：
• 遇到这类词，先记住常见固定搭配
• 例如：けがをする、深呼吸をする、呼吸をする
〜せいで（都怪... / 因为...而造成不好的结果）
意思：表示原因，但多用于带有埋怨、不满、遗憾的负面结果
接续：普通形 + せいで ／ 名词 + の + せいで ／ な形容词 + な + せいで
配達が遅れたせいで、文句を言われてしまった。
雨のせいで、試合が中止になった。
あなたのせいで遅れた。
因为配送晚了，结果被抱怨了。
都怪下雨，比赛取消了。
都怪你，所以迟到了。
重点：
• 「せいで」后面常接不好的结果
• 它常带有责怪、埋怨、遗憾的语气
• 不适合用于明显的好结果：
✗ 日本語を勉強したせいで、合格した。
这种应该用「ので」「おかげで」等更自然
• 和「おかげで」正好相反：
せいで = 因为……（坏结果）
おかげで = 多亏……（好结果）
〜ために（为了...）
意思：表示目的，“为了……”
接续：动词原形 + ために ／ 名词 + の + ために
この問題を解決するために、方法を考えます。
日本へ留学するために、お金をためています。
家族のために働いています。
为了解决这个问题，思考方法。
为了去日本留学，正在存钱。
为了家人而工作。
重点：
• 表示明确目的时，前面用动词原形
• 解決するために = 为了解决
• 也可以接名词：試験のために勉強する = 为考试而学习
• 不要和表示原因的「ために」（由于）混淆，考试里要结合上下文判断是“目的”还是“原因”
〜そうです（传闻：听说...）
意思：表示从别人那里听来的信息，“听说……”“据说……”
接续：普通形 + そうです（な形容词/名词现在肯定可直接接）
田中さんは早退したそうです。
明日は雨だそうです。
あの店は有名だそうです。
听说田中先生早退了。
听说明天会下雨。
听说那家店很有名。
重点：
• 这是传闻用法，不是样态用法（“看起来……”）
• 动词接普通形：帰ったそうです、来るそうです
• い形容词：高いそうです
• 名词/な形容词：便利だそうです、有名だそうです
• 题目里「早退したそうです」= 听说早退了，不是“看起来早退了”
可能形（能够... / 可以...）
意思：表示能力或某种条件下的可能性，“能……”“可以……”
接续：动词变可能形
この店ではさまざまな料理が食べられます。
日本語が話せます。
ここから海が見られます。
在这家店可以吃到各种各样的菜。
会说日语。
从这里可以看见海。
重点：
• 二类动词：食べる → 食べられる
• 一类动词：話す → 話せる、読む → 読める
• 三类动词：する → できる、来る → 来られる（こられる）
• 可能句里宾语常从「を」变成「が」：料理を食べる → 料理が食べられる
• 题目里考的是“可以吃到各种料理”，所以必须用可能表达
受身形（被...）
意思：表示“被别人做了某动作”
接续：动词受身形
医者から毎日運動するように言われました。
先生にほめられました。
社長に呼ばれました。
被医生告知要每天运动。
被老师表扬了。
被社长叫去了。
重点：
• 受身形就是“被……”
• 一类动词：う段 → あ段 + れる；例：言う → 言われる
• 二类动词：去る + られる；例：ほめる → ほめられる
• 三类动词：する → される、来る → 来られる（こられる）
• 本题「オーダーされた」如果按语法看，是“被下命令/被要求”，但和「医者から」「健康のため」搭配非常不自然，所以不是正确选项
〜中（じゅう）（范围：整个...）
意思：表示某个空间、时间、范围的全部，“整个……”“全……”
接续：名词 + 中（じゅう）
世界中の人。
一日中勉強した。
学校中で有名です。
全世界的人。
学了一整天。
在整个学校都很有名。
重点：
• 「世界中」= 全世界、世界各地
• 根据词不同，读音可能是「じゅう」或「ちゅう」，考试里要靠固定搭配记忆
• 本题「世界中（じゅう）多くのサッカーファンが集まった」里的「世界中」表示“全世界范围内”
〜に対して（对于... / 对...）
意思：表示动作、态度、评价所面向的对象，“对……”“对于……”
接续：名词 + に対して
先生に対して失礼な言い方。
この意見に対して反対する。
对老师无礼的说法。
对这个意见表示反对。
重点：
• 强调“面向对象、针对对象”的感觉
• 本题如果说「国に対して違う」就不自然，因为不是“对国家怎么样”，而是“因国家不同而不同”
〜にとって（对...来说）
意思：表示从某人某物的立场来看，“对……来说”
接续：名词 + にとって
私にとって大切な人です。
子どもにとって難しい本です。
对我来说是重要的人。
对孩子来说是难的书。
重点：
• 表示评价标准、立场
• 本题不是在说“对国家来说礼仪不同”，而是在说“因国家不同，礼仪也不同”，所以不能用这个
〜において（在...方面/场合）
意思：较书面，表示“在……方面”“在……场合中”
接续：名词 + において
現代社会において重要な問題。
会議において発表する。
在现代社会中重要的问题。
在会议上发表。
重点：
• 很书面，常见于论文、新闻、说明文
• 本题「国において違う」不自然，因为它强调场合/领域，不表示“因国家不同而有差异”
〜って（口语引用/话题提示）
意思：口语里代替「と」「というのは」「とは」等，表示引用或提出话题
接续：普通形/名词 + って
明日行くって言った。
田中さんって、どの人ですか。
说了明天去。
田中先生是哪位？
重点：
• 很口语
• 本题「引っ越すってこの前言ってた」= “你之前不是说要搬家吗”
• 这里的「って」来自引用，用来承接前面的内容
〜うちに（趁着...）
意思：表示趁某种状态还存在时赶快做某事，“趁着……”
接续：动词辞书形/ない形 + うちに ／ い形容词 + うちに ／ な形容词 + なうちに ／ 名词 + のうちに
熱いうちに食べてください。
忘れないうちにメモします。
请趁热吃。
趁还没忘记先记下来。
重点：
• 表示“某种状态还持续着的时候”
• 本题「熱いうちに皮をむきましょう」= 趁还热的时候削皮
〜ばかり（刚刚...）
意思：表示某动作刚刚完成不久，“刚……”
接续：动词た形 + ばかり
さっき食べたばかりです。
日本に来たばかりです。
刚刚才吃。
刚来到日本。
重点：
• 强调“离现在很近，刚发生完”
• 本题「食べたばかりなのに」= 明明才刚吃过
〜なのに（明明...却...）
意思：表示逆接，带有意外、不满、感叹等语气，“明明……却……”
接续：普通形 + のに ／ 名词・な形容词 + なのに
休日なのに、仕事があります。
勉強したのに、忘れてしまいました。
明明是休息日，却还有工作。
明明学了，却忘了。
重点：
• 比「けど」「が」语气更强，常带“怎么会这样”的感觉
• 本题「食べたばかりなのに、もうおなかがすいてきた」带有意外感：明明刚吃过，怎么又饿了
〜ていく（带去...；……下去）
意思：可表示“把某物带去别处”，也可表示动作、变化朝未来持续
接续：动词て形 + いく
明日、学校に本を持っていきます。
これからもっと寒くなっていきます。
学校に持ってくね。
明天把书带去学校。
之后会变得越来越冷。
我明天带去学校哦。
重点：
• 「持っていく」口语里常说成「持ってく」
• 第9题就是这个缩略形式，不是别的语法
〜といい（要是...就好了）
意思：表示希望、愿望，“要是……就好了”
接续：动词辞书形 / ない形 + といい
晴れるといいですね。
試験に合格するといいですね。
雨が降らないといいです。
要是天晴就好了。
要是考试合格就好了。
要是不下雨就好了。
重点：
• 常用于还没发生的未来事情
• 第10题说的是对两周后天气的希望，所以最自然
尊敬表达「ご〜になる」
意思：把对方的动作说得更尊敬
接续：ご + サ变名词 + になる
ご参加になります。
どなたでもご参加になれます。
ご利用になれます。
参加（尊敬说法）。
任何人都可以参加。
可以使用。
重点：
• 通知、公告、服务说明里很常见
• 「参加いたします」是自谦语，只能说自己，不适合这里对市民说
〜なくなる（变得不...）
意思：表示某种状态从“有”变成“没有”
接续：动词ない形去い + くなる ／ い形容词去い + くなる
海が見えなくなりました。
日本語を忘れなくなりました。
痛くなくなりました。
看不见海了。
变得不再忘日语了。
不疼了。
重点：
• 第12题里是「見える → 見えない → 見えなくなる」
• 表示状态变化，非常重要
〜てもらえない（吗，能不能请你……）
意思：礼貌地请求对方为自己做某事，语气比命令柔和
接续：动词て形 + もらえない（か）
この本を貸してもらえない？
もう一度説明してもらえませんか。
この前借りた小説、もう一回貸してもらえない？
这本书能借给我吗？
能请您再说明一次吗？
前几天借过的那本小说，能不能再借我一次？
重点：
• 表示“我从你那里得到这个动作”
• 比「貸して」更委婉，更像商量、拜托
• 第9题里就是电话中向朋友提出礼貌请求的典型说法
〜でしょう（推量 / 委婉判断）
意思：表示推测、判断，也可使语气更礼貌
接续：普通形 + でしょう
何をあげたら、喜ぶでしょう。
明日は雨でしょう。
これは便利でしょう。
送什么的话，他会高兴呢。
明天大概会下雨吧。
这个应该很方便吧。
重点：
• 可表示“吧、大概、会……”这样的推量
• 也常用于让语气更柔和、更礼貌
• 第8题里「喜ぶだろうか」和「喜ぶでしょうか」意思接近，都是推测“会高兴吗”
〜であれば（如果是……的话）
意思：较正式地表示条件，“如果是……的话”
接续：名词 / な形容词词干 + であれば
市民であれば、無料で参加できます。
必要であれば、連絡してください。
如果是市民，就可以免费参加。
如果有需要，请联系我。
重点：
• 比口语的「だったら」「なら」更正式，常见于通知、公文、说明文
• 第11题是市政府主页上的通知，所以用「市民の方であれば」最自然
〜のだ / 〜んだ（说明、解释）
意思：表示说明背景、强调理由、补充解释
接续：普通形 + のだ／んだ（名词・な形容词现在肯定常接 なのだ／なんだ）
明日は休みなんだ。
今日は早く帰るんだ。
どうして行かないんですか。
明天是休息日哦。
今天我是要早点回去的。
为什么不去呢？
重点：
• 用来补充说明“是这么一回事”
• 「晴れるんだね」像是在说明“原来会晴啊”
• 第10题不是说明事实，而是表达希望，所以不能选这种解释语气
〜と比べると
意思：和……相比的话
接续：名词 + と比べると
去年の夏と比べると、今年は涼しいです。
前回と比べると、よくできています。
和去年的夏天相比，今年比较凉快。
和上次相比，做得很好。
重点：
• 「Aと比べると、B」= “和A相比，B……”
• 这里的「と」是比较对象标记
• 排序题里常拆成「去年の夏に / 比べると」这样的形式来干扰你
〜だけで（只靠...；只要...就...）
意思：表示条件很少，“仅仅……”就足够
接续：名词 + だけで ／ 动词辞书形 + だけで
材料を混ぜて冷やすだけで、チーズケーキができます。
見るだけで分かります。
只要把材料混合后冷却，就能做好芝士蛋糕。
只看就明白了。
重点：
• 表示“程序很简单、只需要这些就够了”
• 本题中「材料を混ぜて冷やすだけ」后面再接「だから」不自然；最自然是「だけで、誰でも簡単に作れる」这种结构
いつのまにか
意思：不知不觉地；在没注意时
接续：常放在句中，修饰后面的整体事件
本を読んでいたら、いつのまにか外が暗くなっていた。
いつのまにか春になりました。
看书的时候，不知不觉外面变暗了。
不知不觉就到春天了。
重点：
• 常和状态变化一起出现：暗くなる、終わる、寝る 之类
• 语气重点在“自己没察觉到，结果已经变了”
• 在排序里它通常放在“变化结果”前面
〜たとしても
意思：即使……的话也……
接续：动词た形 + としても ／ 名词・な形容词 + だとしても
雨が降ったとしても、試合は中止になりません。
無理だとしても、まずやってみましょう。
即使下雨，比赛也不会取消。
即使不容易，也先试试看吧。
重点：
• 比「〜ても」更书面、假设感更强
• 「雨が降ったら」是“如果下雨”；「雨が降ったとしても」是“就算下雨也……”
• 本题正是用它来表示“就算下雨，比赛也不会取消”
〜んだけど
意思：可是……；不过……；带铺垫、说明、缓和语气
接续：普通形 + んだけど（名词・な形容词现在肯定常接 なんだけど）
雨が降ったとしても、中止にならないんだけど、無理して来なくてもいいよ。
ちょっとお願いがあるんだけど。
就算下雨也不会取消，不过你不用勉强来。
我有点事想拜托你，不过……
重点：
• 「んだ」表示说明，「けど」表示转折或铺垫
• 合起来常形成很自然的口语表达
• 本题里前半句给出说明，后半句再温和补充“你不用勉强来”
