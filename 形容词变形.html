形容词变形总结

い形容词 & な形容词 全变形规则 · JLPT N5–N3 · 更新于 2026年3月19日

い形容词 vs な形容词 概览 OVERVIEW

I-ADJECTIVE
い形容词
词尾以 い 结尾，变形时去掉い
  • 高い（たかい）贵的/高的
  • 忙しい（いそがしい）忙的
  • おもしろい 有趣的
  • いい（特殊）好的
NA-ADJECTIVE
な形容词
修饰名词时加 な，变形类似名词
  • 静かな（しずかな）安静的
  • 元気な（げんきな）精神好的
  • 好きな（すきな）喜欢的
  • きれいな 漂亮的
⚠ 注意：有些词虽然以 い 结尾，但其实是 な形容词！常见的有：きれい（漂亮）、嫌い/きらい（讨厌）、有名/ゆうめい（有名）。判断方法：修饰名词时加「な」就是な形容词。

拿到一个词，怎么判断它是什么词 PART OF SPEECH

先判断词性，再判断怎么变
日语学习里最重要的顺序：先看这个词是什么 → 再看它能怎么变
词类 最常见判断线索 常见变形/接续 例子
动词 常表示动作；词典形常以う段或る结尾 ます、て、ない、た、たい 書く、食べる、来る
い形容词 多以「い」结尾，表示性质状态 くない、かった、くて、く 高い、忙しい
な形容词
（形容动词）		 修饰名词时要加「な」 だ、です、な、で、に 静か、元気、きれい
名词 表示人、物、地点、概念 だ、です、の、に、になる 学生、本、日本
副词 主要修饰动词、形容词、整句 通常不做“时态变形” とても、ゆっくり、急に
💡 你要特别记住：形容动词 = な形容词。很多中文教材写“形容动词”，很多入门教材写“な形容词”，说的是同一类词。
⚠ 不能只看最后一个假名来死记。
比如：きれい 虽然以「い」结尾，但它是な形容词 / 形容动词，因为说的是「きれいな花」，不是「きれい花」。
最适合初学者的判断步骤
① 先问：这个词是不是“动作”？如果是，多半是动词。
② 再问：它是不是直接表示“高、忙、冷、可爱”这种性质？如果是，多半是形容词。
③ 修饰名词时要不要加「な」？要加 = な形容词。
④ 如果更像“人、东西、地点、事情的名称”，通常是名词。
⑤ 如果主要用来修饰动作的方式、程度，通常是副词。
例：
• 食べる → “吃”是动作，所以是动词。
• 高い → “高/贵”是性质，所以是い形容词。
• 静か → 说「静かな部屋」，所以是な形容词。
• 学生 → 是身份名称，所以是名词。
• ゆっくり → 说「ゆっくり歩く」，修饰“走”，所以是副词。

い形容词 — 基本规则 I-ADJ BASICS

核心变形法则
基本原则：い形容词的所有变形都是 去掉词尾「い」，然后加上对应的后缀。高い → 高 + 后缀
💡 记忆技巧：い形容词变形就像"换衣服"——脱掉「い」这件衣服，换上不同的"新衣服"。

い形容词 — 谓语形式（肯定/否定 × 现在/过去） I-ADJ PREDICATE

以「高い（たかい）」为例
简体 敬体
现在肯定 高い直接使用 高いです+ です
现在否定 高くないい → くない 高くないです / 高くありません两种均可
过去肯定 高かったい → かった 高かったです+ です
过去否定 高くなかったい → くなかった 高くなかったです / 高くありませんでした两种均可
❌ 常见错误：高いだ ← 绝对不可以！い形容词后面不能加「だ」。正确：高い ○ 错误：高いだ ✗
この本は高い。/ 这本书很贵。
昨日は忙しくなかった。/ 昨天不忙。

い形容词 — 修饰名词 I-ADJ + NOUN

い形容词 + 名词（直接连接）
规则：い形容词 直接 放在名词前面，不需要任何变化。高い + 山 → 高い山（たかいやま）
おもしろい映画を見ました。/ 看了一部有趣的电影。
忙しい人はいつも時間がない。/ 忙碌的人总是没有时间。

い形容词 — て形 I-ADJ TE FORM

い → くて（用于并列、原因等）
高い → 高くて
忙しい → 忙しくて
おもしろい → おもしろくて
💡 用法：て形可以用来——① 并列两个形容词：安くておいしい（又便宜又好吃）② 表示原因：忙しくて行けない（因为忙所以去不了）
この店は安くておいしい。/ 这家店又便宜又好吃。
頭が痛くて、学校を休みました。/ 因为头疼，请了学校的假。

い形容词 — 副词形式 I-ADJ ADVERB

い → く（变成副词修饰动词）
早い → 早く（早早地）
高い → 高く（高高地）
早く起きてください。/ 请早点起床。
大きく書いてください。/ 请写大一点。
💡 「〜くなる」= 变得〜 高くなる（变贵）、寒くなる（变冷）、大きくなる（变大） 这也是副词形式 + なる 的应用。

い形容词 — 条件形（ば形） I-ADJ CONDITIONAL

い → ければ（如果〜的话）
高い → 高ければ（如果贵的话）
安い → 安ければ（如果便宜的话）
忙しい → 忙しければ（如果忙的话）
安ければ買います。/ 如果便宜就买。
天気がよければ、出かけましょう。/ 如果天气好的话，就出门吧。
💡 否定条件：〜くなければ（如果不〜的话） 高くなければ = 如果不贵的话

い形容词 — 特殊：いい（よい） I-ADJ SPECIAL

いい 的所有变形都基于「よい」
⚠ 超级重要：「いい」（好的）是最特殊的い形容词！原形可以说「いい」，但 所有变形都要用「よ-」，不能用「い-」！
变形 正确 ✓ 错误 ✗
原形 いい / よい —
否定 よくない いくない
过去 よかった いかった
过去否定 よくなかった いくなかった
て形 よくて いくて
副词 よく いく
条件 よければ いければ
💡 同类词：「かっこいい」（帅的）也一样→ かっこよかった、かっこよくて
昨日の映画はよかった。/ 昨天的电影很好看。
天気がよくて、散歩しました。/ 天气好，去散步了。

な形容词 — 基本规则 NA-ADJ BASICS

核心变形法则
基本原则：な形容词的变形模式与 名词 几乎相同。把它当作名词来处理就对了！静か + だ / です / じゃない / だった …
💡 记忆技巧：な形容词 = "形容词外表，名词内心"。变形规则跟着名词走！

な形容词 — 谓语形式（肯定/否定 × 现在/过去） NA-ADJ PREDICATE

以「静か（しずか）」为例
简体 敬体
现在肯定 静かだ+ だ 静かです+ です
现在否定 静かじゃない+ じゃない 静かじゃないです / 静かではありません两种均可
过去肯定 静かだった+ だった 静かでした+ でした
过去否定 静かじゃなかった+ じゃなかった 静かじゃなかったです / 静かではありませんでした两种均可
この部屋は静かです。/ 这个房间很安静。
昨日は暇じゃなかった。/ 昨天不空闲。

な形容词 — 修饰名词 NA-ADJ + NOUN

な形容词 + な + 名词
规则：な形容词修饰名词时，中间必须加「な」。静か + な + 場所 → 静かな場所（安静的地方）
元気な子供が遊んでいます。/ 精力充沛的孩子在玩耍。
有名な歌手が来ました。/ 著名的歌手来了。
❌ 常见错误：静か場所 ← 缺少「な」！正确：静かな場所 ○ 错误：静か場所 ✗

な形容词 — て形 NA-ADJ TE FORM

な形容词 + で（用于并列、原因等）
静か → 静かで
元気 → 元気で
きれい → きれいで
💡 对比记忆：い形容词て形：〜くて（高くて）な形容词て形：〜で（静かで）完全不同的形式！考试常考！
この町は静かできれいです。/ 这个城镇又安静又漂亮。
暇で、映画を見ました。/ 因为有空，看了电影。

な形容词 — 副词形式 NA-ADJ ADVERB

な形容词 + に（变成副词修饰动词）
静か → 静かに（安静地）
きれい → きれいに（漂亮地）
静かにしてください。/ 请安静。
部屋をきれいに掃除しました。/ 把房间打扫得很干净。
💡 「〜になる」= 变得〜 元気になる（变精神）、きれいになる（变漂亮）、静かになる（变安静） 对比：い形容词用「〜くなる」，な形容词用「〜になる」

な形容词 — 条件形 NA-ADJ CONDITIONAL

な形容词 + であれば / なら(ば)（如果〜的话）
① 静か + であれば（较书面）
② 静か + なら(ば)（较口语，常用）
③ 静か + だったら（たら条件，口语常用）
静かなら、ここで勉強できます。/ 如果安静的话，可以在这里学习。
暇だったら、遊びに来てください。/ 如果有空的话，请来玩。

名词与副词的相关变形 NOUN / ADVERB

名词其实不是“不会变”，而是按名词规则变
形式 名词例：学生 意思
现在肯定 学生だ / 学生です 是学生
现在否定 学生じゃない / 学生ではありません 不是学生
过去肯定 学生だった / 学生でした 曾经是学生
过去否定 学生じゃなかった / 学生ではありませんでした 以前不是学生
修饰名词 学生のかばん 学生的包
变化/成为 学生になる 成为学生
💡 你可以把名词和な形容词放在一起记：它们后面的很多变化非常像。
学生だ / 静かだ、学生じゃない / 静かじゃない、学生だった / 静かだった。
副词一般不是“时态变形”，而是“来源变化”
来源 变法 例子 意思
い形容词 い → く 早い → 早く 早地
な形容词 + に 静か → 静かに 安静地
固定副词 直接使用 とても、すぐ、ゆっくり 非常、马上、慢慢地
⚠ 很多教材会说“副词变形”，但更准确地说，常常是别的词变成副词形式。
比如：高い → 高く、静か → 静かに。
而「とても」这种词本身就是副词，通常不再做这类变化。

词性和形态之间的关系图 RELATIONSHIP

一张图看懂你现在最困惑的地方
动词：書く → 書きます → 書きたい → 書きたくない
い形容词：高い → 高くない / 高かった / 高くて / 高く
な形容词：静か → 静かだ / 静かな / 静かで / 静かに
名词：学生 → 学生だ / 学生の / 学生になる
サ变：勉強（名词）→ 勉強する（动词）→ 勉強します → 勉強したい
💡 这里最关键的两句：
1. ます不会把普通词变成动词，它只能接在动词系统里。
2. たい后面的变化像い形容词，所以「行きたい、行きたくない、行きたかった」才会长得像高い、高くない、高かった。
把你最容易混淆的三组关系并排看
问题 正确理解
为什么很多词后面加ます像动词？ 因为它们本来就是动词，或者先经过「する」变成动词。
为什么たい像い形容词？ 因为たい在语法功能上带有形容词性质，所以后半段按い形容词方式变化。
为什么形容动词和名词很像？ 因为な形容词（形容动词）后面的很多活用形式，本来就和名词系统接近。

考试常见陷阱 TOP 5 EXAM TRAPS

1
以い结尾的な形容词
词 类型 修饰名词
きれい な形容词 きれいな花
嫌い/きらい な形容词 嫌いな食べ物
有名/ゆうめい な形容词 有名な人
💡 判断技巧：看修饰名词时加「な」还是直接接。加「な」= な形容词
2
い形容词 + だ 的错误
❌ 错误：高いだ、おもしろいだ、忙しいだ
✓ 正确：高い、おもしろい、忙しい

い形容词作谓语时，后面不能加「だ」！
要用敬体时加「です」，但绝不加「だ」。
3
いい的变形必须用よ-
❌ 错误：いくない、いかった、いくなかった
✓ 正确：よくない、よかった、よくなかった

「いい」是最特殊的い形容词，所有变形都要换成「よ-」开头！
4
て形混淆
形容词类型 て形 例子
い形容词 〜くて 高くて、忙しくて
な形容词 〜で 静かで、元気で
❌ 常见错误：静かくて（×）、高くてで（×）
✓ 记住：い→くて、な→で，完全不同！
5
くなる vs になる
类型 变得〜 例子
い形容词 〜くなる 高くなる（变贵）、寒くなる（变冷）
な形容词 〜になる 元気になる（变精神）、静かになる（变安静）
名词 〜になる 先生になる（成为老师）
❌ 错误：高いになる（×）、元気くなる（×）
✓ 记住：い→く、な/名词→に
